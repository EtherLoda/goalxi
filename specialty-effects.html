阅读须知

  • 引擎原则 (v2.7+): 引擎不再"特挑"特技球员参与事件。所有选人环节是 attribute 评估，特技只对被选中的球员生效 — 你可以理解为"如果一个 AERIAL_THREAT 球员被选为头球射门者，他有 1.10× 头球加成；不是引擎故意找他来头球"。
  • 系数缩放: 所有 base 系数（> 1 的"加成"和 < 1 的"减免"）都走同一公式 base ^ TIER_MULT[tier] — Gold 强、Silver 中、Bronze 弱。
  • 决策类 (TACKLER midfield_control): 选最高 + 每个 holder +5% depth bonus（无上限） — 3 个 Silver TACKLER 累计 = 1.32×，1 Gold = 1.29×。
  • 强度类 (TACKLER/WALL push_defense): 所有 holder 系数相乘，cap 1.80 — 3 个 Silver 就触顶。
  • v2.8 找补: v2.7 让 POACHER / SPEEDSTER / AERIAL_THREAT / PLAYMAKER / CROSSER / DRIBBLER 6 个特技失去"被特挑"加权，v2.8 在"被选中后效果侧"补回 — 凡带 v2.8 找补 标签的都是这一轮新加的。

如何读懂这张表
  • 每个 hook 触发条件都明确写出（哪些 event、哪些 shot type、哪些 pass type），不是泛泛说"对射门有加成"。
  • v2.8 找补 = v2.7 削弱后 v2.8 新加的 hook，对应 commit 6e008a3。
  • v2.5 wired / v2.6 移位 = 之前 commit 接上的或移位的 hook（不是 v2.8 这次的，但属于近期 history）。
  • tier 数字（Gold/Silver/Bronze）都是实际生效值（已经走 applyTierMultiplier(base, tier)），不是 base 系数。tier 概率: Gold 5% / Silver 15% / Bronze 30% / No Spec 50%。
  • coef < 1 的（如 foul_rate 0.50）走同一公式但含义翻转：tier 越高，减免越多 — Gold COMPOSED 实际犯规率仅 37.9%。
