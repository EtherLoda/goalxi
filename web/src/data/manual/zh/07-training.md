# 训练

每场比赛之间的那一周,你的球队在**训练**。训练的目的是让球员:
- 恢复体能(每场比赛都消耗)
- 涨技能(长期成长)
- 涨经验(见 [第 4 章](04-player-attributes.md))

这一章讲**训练怎么排**、**教练怎么请**、**球员怎么分**、**什么时候技能会涨**。

> 训练界面在"训练场"。体能 / 经验 / PWI 是什么见 [第 4 章](04-player-attributes.md)。

---

## 训练时间表

- **每周训练**:**周四**结算(球员数据更新)
- **每周一次调机会**:体能训练强度**一周只能改一次**
- **教练分配**:随时可改(改了下个结算日生效)

> 周一还有 35+ 岁衰退系统的后台跑(见 [第 4 章](04-player-attributes.md))。**那是衰退,不是训练**——两件事分开看。

---

## 体能训练强度(每队一个设置)

**体能训练强度**是全队共用的一个 0-1 滑块,**默认 0.1**。

**作用**:**影响体能恢复 vs 专项训练的分配**——
- 调**高**:**球员恢复更多体能**(消耗得慢,比赛中不容易累)
- 调**低**:**专项训练点数变多**(技能涨得快,但球员容易疲劳)
- **折中**:大部分队用默认值附近,赛季末调整

**怎么调**:
- 进入训练场,看体能训练滑块
- 拖到目标值
- **保存** — 一周只能改一次
- 改完到下个周四结算时生效

> **别一直调**——频繁改反而打乱节奏。一般**赛季初调高**(球员休整)→ **赛季中调中**(平衡)→ **赛季末再调高**(为下赛季蓄力)。

---

## 7 种教练(岗位)

| 岗位 | 作用 |
|---|---|
| **主教练** | 全队训练基础加成(每升 1 级,加得多) |
| **体能教练** | 体能恢复加成 |
| **技术教练** | 训练 4 项技能:射门 / 传球 / 盘带 / 防守 |
| **心理教练** | 训练 2 项技能:跑位 / 沉着 |
| **定位球教练** | 训练 2 项技能:任意球 / 点球 |
| **门将教练** | 训练 3 项门将技能:反应 / 扑救 / 高空球 |
| **队医** | 伤病相关(本章不深入) |

> 体能 / 定位球 / 任意球 / 点球 训练速度**特别快**(短时间就能涨)。精神类(跑位 / 沉着)也较快。体能类(速度 / 力量)较慢。

**教练能带多少人**:
- **主教练**:全队
- **体能教练**:全队
- **专项教练**(技术 / 心理 / 定位球 / 门将):**每个最多 3 个球员**
- **专项教练总数**:**每队最多 2 个**(不含主教练、队医)

**教练本身**:
- 有**等级**(**S / A / B / C / D** 5 档,S 最高 D 最低),等级越高训练加成越大
- 有**签约费**和**周薪**(经济压力,见 [第 9 章:财政](09-finance.md))
- 可**升级**到更高等级
- 可**解约**(该教练名下的球员会变回未分配)

---

## 怎么分配球员(拖拽)

每个专项教练**最多带 3 个球员**。分配流程:

1. 训练场 → 选一个专项教练卡片
2. **拖球员**到教练名下(从"未分配球员"区)
3. 教练卡片上**显示已带人数**(如 2/3)
4. **保存**分配

**几个规则**:
- **同一球员可以被多个专项教练带**(每被带 1 次,该教练就给该球员周点数)
- **门将只能给门将教练**带
- 教练满 3 人 → 不能再加
- 训练场**专项教练已满** → 不能请第 3 个专项教练

---

## 教练的"主要训练技能"

每个专项教练可以**选 1 个"主要训练技能"**:
- 技术教练:可选 4 项之一(射门 / 传球 / 盘带 / 防守)
- 心理教练:跑位 / 沉着
- 定位球教练:任意球 / 点球
- 门将教练:反应 / 扑救 / 高空球

**怎么用**:
- 教练训练该球员时,**优先练"主要训练技能"**
- 球员该技能**还没到潜力顶** → 直接练它
- 该技能**已经到顶** → 随机选另一个没到顶的技能
- **不选**也行 → 每次随机练

> 怎么改:训练场 → 教练卡片 → "训练技能"下拉。

---

## 技能怎么涨

每周结算(周四)时,被指派的球员会获得**专项训练点数**,按下面的规则花掉:

1. **优先花到"主要训练技能"**(如果该技能还没到顶)
2. 否则**随机挑一个没到顶的技能**
3. 点数按**当前技能等级**换算成**技能涨幅**:
   - **低级技能**涨得快(便宜)
   - **高级技能**涨得慢(贵,越高级越贵)
4. 涨到**潜力顶**就停(不超过 potentialSkills 的值)

**实战含义**:
- **低潜力球员 + 高潜力球员**都练 → 低潜力的很快涨满(浪费),高潜力的慢但收益大
- **别只练 1 项**——球员成长是分散的,练到顶的先放着
- **选好"主要训练技能"**——一个赛季 16 周,练啥基本固定

> 涨多少跟**年龄**、**教练等级**、**该技能训练速度**都有关系(见下文)。

---

## 年龄影响(训练效率)

**训练效率按年龄线性下降**:
- **17 岁**:满效率(1.0)
- **17-36 岁**:线性下降
- **36 岁及以上**:最低效率

**实战含义**:
- **年轻人练得快**,涨得明显
- **老将练得慢**,同样的教练 / 同样的技能点数,涨得更少
- 36+ 岁:即使有教练,也很难有大幅成长
- 跟 [第 4 章](04-player-attributes.md) 的 35+ 衰退是两回事——一个是涨得慢,一个是会掉

---

## 历史训练报告(查记录)

训练场底部有**每周训练更新**列表:
- 哪个赛季 / 哪个轮次
- 每个球员的**训练前技能 / 训练后技能 / 涨了哪些**
- 可按赛季 + 轮次定位历史周

**怎么用**:
- 看到自己的核心球员有没有按预期涨
- 检查"为什么这周某球员没动"——可能未分配教练 / 已到顶 / 年龄过大
- 规划下一周的分配调整

---

## 完整操作流程(总结)

1. **设置体能训练强度** → 保存(一周一次)
2. **签约教练**(如果你没有或要升级)
3. **升级教练**(提高等级,加训练加成)
4. **分配球员**到教练(拖拽,每教练最多 3 人)
5. **设教练的"主要训练技能"**(可选)
6. **等周四结算**
7. **看历史训练报告**确认涨了

---

## 常见错误

❌ **体能训练强度调太高 / 太低**:**调高 = 球员不容易累但技能慢涨,调低 = 反过来**。极端值都会失衡,默认值附近最稳
❌ **一周改多次体能强度**:**系统只让改一次**,改完等下周四
❌ **请 3 个专项教练**:**最多 2 个**,且每队总数含队医 / 主教练都不算
❌ **一个教练带 4 个球员**:**最多 3 个**
❌ **"我签了技术教练但球员没涨"**:可能球员该项技能**已到潜力顶**——选另一项,或换球员
❌ **"我改了'主要训练技能'但还是练别处"**:该技能**已到顶**才会换去随机练
❌ **"36 岁老将练不上去"**:**年龄降效率**,正常,不是 bug
❌ **"老将技能掉了"**:**35+ 衰退系统**(见 [第 4 章](04-player-attributes.md)),跟训练无关
❌ **解约教练后球员消失**:**不会**,球员回到"未分配"区,只是没人带
❌ **忘记选"主要训练技能"**:**没事**,系统随机练一个未到顶的技能,但效率不如指定

## 跟其他概念的关系

| 概念 | 关系 |
|---|---|
| **技能**(第 2 章) | 训练涨的是技能,**到潜力顶就停** |
| **位置**(第 3 章) | 涨技能时考虑位置(头牌技能优先涨) |
| **其他属性**(第 4 章) | 训练同时涨经验,影响状态 / form |
| **教练**(第 8 章) | 教练等级越高,训练加成越大 |
| **财政**(第 9 章) | 教练**有工资**,越高等级越贵 |
| **35+ 衰退** | 跟训练**不冲突**——一个涨,一个掉;两套系统 |
