# 杯赛系统

杯赛 = **跨联赛**的**单淘汰**赛,每赛季 1 个。MVP 只有 1 种杯赛:**National Cup**,L1-L4 全部 1360 队都参加。**冠军是真正的"全国冠军"**(跟 L1 联赛冠军不一样)。

这一章讲**杯赛结构、参赛资格、淘汰流程、奖金**。**联赛**见 [第 20 章](20-league-system.md)。

---

## 一、为什么有杯赛

- **跨联赛**:联赛是同 16 队的小循环(L1 跟 L1,L4 跟 L4),杯赛把 L1-L4 全拉进来
- **单淘汰**:每场输赢 = 留下 / 回家,**没有积分**,**没有升降级**
- **真正的"全国冠军"**:L1 冠军 = L1 这个小联赛的冠军;**National Cup 冠军 = 全国冠军**(无论你什么级别,都可能拿到)

> **Hattrick FA Cup 模式** — 顶级队(L1)只踢几场,低级别队(L4)从最初几轮踢起,业余队有机会爆冷豪门。

---

## 二、National Cup 结构(L1-L4)

MVP **每赛季 1 个** National Cup,**所有 1360 队**都进,**单淘汰**,**12 轮**决出冠军。

### 按级别分轮进入

| 级别 | 进入轮次 | 踢的轮数 |
|---|---|---|
| **L1**(16 队) | **R6**(从 32 强开始) | 6 轮(R6-R11) |
| **L2**(64 队) | **R4**(从 64 强开始) | 8 轮(R4-R11) |
| **L3**(256 队) | **R2**(从 256 强开始) | 10 轮(R2-R11) |
| **L4**(1024 队) | **R0**(从 1024 强开始) | 12 轮(R0-R11) |

> 越低级别踢的轮数越多,顶级队从后面进。**总轮数 = 12**(R0 到 R11)。

### 流程图(简化)

```
R0:  1024 L4 队 ── 512 场比赛 ──→ 512 队晋级
R1:   512 队    ── 256 场       ──→ 256 队晋级
R2:   256 + 256 L3 = 512 队     ──→ 256 晋级
R3:   256 队    ── 128 场       ──→ 128 晋级
R4:   128 + 64 L2 = 192 队      ──→ 96 晋级
R5:    96 队    ──  48 场       ──→  48 晋级
R6:    48 + 16 L1 =  64 队     ──→  32 晋级
R7:    32 队    ──  16 场       ──→  16 晋级
R8:    16 队    ──   8 场       ──→   8 晋级
R9:     8 队    ──   4 场       ──→   4 晋级
R10:    4 队    ──   2 场       ──→   2 晋级(决赛两队)
R11:    2 队    ──   1 场(决赛) ──→  1 队 = 冠军
```

> 每轮比赛数 = 上一轮晋级数 / 2(单淘汰)。**没有 byes**(所有轮都是偶数,自然半数)。

## 三、赛季节奏

- **每赛季 1 个 National Cup**
- **每轮 1 周** = 12 周跑完
- **比赛日:周二 + 周四**(`GAME_SETTINGS.MATCH_KICKOFF_HOUR_UTC: 6:00 UTC = 14:00 北京时间`)
- **R0 在赛季第 2 周开打**(R0 = `initDate + 7 days` 之后,留 1 周给联赛)
- **决赛 R11 在赛季第 13 周**(杯赛跑 12 周,占赛季 12-13 周)
- **联赛 + 杯赛不冲突**:联赛周三 + 周六,杯赛周二 + 周四

> 实战感知:
> - L4 / L3 队:赛季 1-13 周都在打杯赛(每周 1-2 场),跟联赛交叉
> - L1 / L2 队:赛季前 6 周**不打杯赛**,从 R6 开始加入(第 7-13 周)
> - **L1 队最多打 6 场杯赛**;**L4 队最多打 12 场**(一路从 R0 踢到 R11)

## 四、淘汰规则

| 情况 | 规则 |
|---|---|
| **90 分钟战平** | **加时 30 分钟**(上 15 + 下 15,**无补时**)+ 进球数决胜 |
| **加时仍平** | **点球大战**(5 轮 + 突然死亡,链 [第 6 章](06-match-basics.md)) |
| **平局** | 杯赛**没有**(不像联赛有平局),必须分出胜负 |
| **主客场** | 杯赛是**单场淘汰** — 没有"两回合总比分" |

> **跟联赛区别**:联赛 90 分钟平 = 各拿 1 分(平局);**杯赛 90 分钟平 = 加时 + 点球**。同一场比赛,联赛规则 vs 杯赛规则不同。

## 五、你能看到什么(都是**公开**端点)

| 端点 | 用途 |
|---|---|
| `GET /cups` | 列所有杯赛(可按 `season` / `type` 筛选) |
| `GET /cups/:id` | 单杯赛 meta(name / type / status / prize pool) |
| `GET /cups/:id/bracket` | 完整 bracket — 杯赛 meta + 每轮 + 每场 |
| `GET /cups/:id/rounds/:round/matches` | 只看一轮的 matches(高频轮询用) |

### CupResDto 字段

| 字段 | 含义 |
|---|---|
| `id` | 杯赛 id |
| `season` | 赛季号 |
| `type` | `NATIONAL`(MVP 只有这一种;预留 `SENIOR` / `TROPHY` / `VASE`) |
| `name` | 例:"National Cup 2026" |
| `status` | `pending` / `in_progress` / `completed` / `cancelled` |
| `prizeCurrency` | 币种(默认 `CNY`) |
| `prizePool` | 奖金池(winner + runner-up + round bonuses,**bigint** 序列化为 number) |

### CupBracketResDto 字段

| 字段 | 含义 |
|---|---|
| `cup` | 杯赛 meta |
| `rounds` | 12 个 round,每个含 matches(每场的 home/away/score) |

## 六、奖金(prize pool)

| 名次 | 奖金 | 说明 |
|---|---|---|
| **冠军** | 大头(具体看赛季) | `prizePool` 主要给冠军 |
| **亚军** | 较小 | 决赛输家 |
| **4 强** | 较小 | R10 输家 |
| **8 强 / 16 强** | 极少 | 后续轮次输家 |
| **早期淘汰** | 0 | 不发奖 |

> MVP 阶段 `prizePool` 字段存在但**当前默认 0**,奖金数字是**预留的**,等赛季结算时填。
>
> 实际拿到手的钱 = 奖金 - 不存在手续费(目前没手续费)

## 七、状态机

每个杯赛有 4 个状态:

```
PENDING (entries + bracket 已生成,首轮未开始)
   ↓
IN_PROGRESS (R0+ matches 已排期/已踢)
   ↓
COMPLETED (决赛踢完,冠军定)
   ↓ (或)
CANCELLED (异常情况)
```

> **PENDING → IN_PROGRESS** 触发:第一场比赛的 `scheduledAt` 到点,worker 处理
> **IN_PROGRESS → COMPLETED** 触发:决赛 R11 踢完,系统自动判冠军

## 八、参赛资格(对球员 / 球队)

**球队**:
- 你的球队自动参赛(MVP 强制全 1360 队都进),**不能退出**
- 你**不能选**进哪一轮 — 由你的联赛等级决定(L1 进 R6,L4 进 R0)

**球员**:
- 球员**没有**"杯赛专属"概念,**只是按场次踢**
- 同一场杯赛对所有球员的 EXP 倍率 = **1.0×**(跟联赛一样,链 ch 6)
- **无特殊加成** — 杯赛 = 另一个"比赛类型",没"杯赛专家"特性

---

## 九、跟联赛的区别(总览)

| 维度 | 联赛 | 杯赛 |
|---|---|---|
| 范围 | 16 队 / 联赛 | 1360 队(全国) |
| 形式 | 双循环(主客 2 场) | **单淘汰**(1 场定胜负) |
| 场次 | 30 场 / 队 / 赛季 | L1 最多 6,L2 最多 8,L3 最多 10,L4 最多 12 |
| 节奏 | 周三 + 周六 | 周二 + 周四 |
| 周期 | 16 周 | 12 周 |
| 升降级 | ✅ 有 | ❌ 无 |
| 平局 | ✅ 有(各 1 分) | ❌ 无(加时 + 点球) |
| 冠军 = | 联赛冠军 | **全国冠军** |
| EXP 倍率 | 1.0× | 1.0× |

## 十、跟其他概念的关系

| 概念 | 关系 |
|---|---|
| **联赛**(第 20 章) | 跟杯赛**完全独立** — 你既踢联赛又踢杯赛(只要还在杯赛中) |
| **比赛**(第 6 章) | 杯赛比赛 `matchType = 'CUP'`,**有** `cupId` 字段;联赛 `matchType = 'LEAGUE'`,有 `leagueId` |
| **球员**(第 4 章) | 球员的杯赛比赛 = 1.0× EXP,跟联赛一样 |
| **青年**(第 19 章) | 青年球员属于球队 → 球队进杯赛 → 青年能踢杯赛 |
| **转会**(第 18 章) | 杯赛期间能转会,但**踢杯赛的人不能进转会市场**(要等当前比赛结束) |
| **球员事件历史**(`player-event-types` 条目) | 杯赛冠军成员 → 球员详情页可能有 `CHAMPIONSHIP_TITLE` 事件(链 ch 4) |
| **特性**(第 4 章) | 没有"杯赛加成"特性,杯赛 = 12 场高强度比赛而已 |

## 十一、能做 / 不能做

### ✅ 能做

- 看任何杯赛的全 bracket(公开)
- 看每一轮的 matches(可轮询)
- 看自己球队在杯赛中的位置和对手
- 踢杯赛获得经验(1.0× 倍率)

### ❌ 不能做(玩家侧)

- **退出杯赛** — MVP 强制参赛,不能 `withdraw`
- **选择对手** — 杯赛配对是**种子 + bracket** 自动的,不是 Hattrick 式的"挑对手"
- **改赛程** — `POST /cups/:id/...` 没有创建 / 改期端点,都是 admin + scheduler 控制
- **重复参赛** — 一支球队**只能**在每赛季的杯赛中**出现一次**(被淘汰就回家)
- **跨赛季**杯赛存档 — MVP 阶段杯赛记录是当季的,跨赛季后旧数据(可能)归档

### ❌ MVP 限制

- **只有 1 种杯赛**(NATIONAL),`SENIOR` / `TROPHY` / `VASE` 字段预留但**不生成**
- **奖金池 0** — `prizePool` 字段有,数据流**没填**
- **没有第二个杯赛** — 不能"同时打 National Cup + Senior Cup"

## 十二、常见错误(关于杯赛)

❌ **"L1 冠军 = 全国冠军"**:L1 冠军只是 L1 联赛冠军。**National Cup 冠军才是全国冠军**
❌ **"杯赛 90 分钟平 = 各拿 0 分"**:杯赛**没有平局**,90 分钟平 = **加时 + 点球**
❌ **"可以退赛不打杯赛"**:**不能**。MVP 强制全 1360 队参赛
❌ **"可以选择打哪一轮"**:由**你的联赛等级**决定(L1 队 R6 进,L4 队 R0 进)
❌ **"决赛两回合"**:杯赛**单场淘汰**,没有两回合
❌ **"L1 队要从 R0 踢起"**:不,L1 队**直接 R6**(32 强),前面 6 轮**休息**
❌ **"冠军奖池 = 100 万"**:`prizePool` 字段默认 0,**当前不填具体值**
❌ **"杯赛经验 = 联赛经验"**:都是 **1.0×** 基准,没区别
❌ **"青年球员不能踢杯赛"**:**能**,青年 = 球员,跟 senior 一样上场
❌ **"买人不能买杯赛中的"**:**能**。杯赛中**球员仍可挂牌**,但当前比赛的**正在场上**的不能立刻转手
❌ **"季军附加赛"**:杯赛是**单淘汰**,**没有季军赛**(半决赛两个输家都不打,直接结束)

## 十三、实战流程(球队经理视角)

### 杯赛目标(按联赛级别)

| 你的级别 | 现实杯赛目标 |
|---|---|
| **L4** | 走到 R4 就算成功(以弱胜强 4 轮);冲到 8 强就是惊喜 |
| **L3** | 8 强是底线;4 强 = 顶级表现 |
| **L2** | 4 强是目标;决赛 = 成就 |
| **L1** | 夺冠 = 全国冠军,这是你的**赛季最高目标** |

### 什么时候重视

- **L4 / L3** — **每个对手都要研究**(很可能撞到 L1 / L2 强队)
- **L1 / L2** — **R6 之后**才进,从 32 强开始认真
- **R0-R1 阶段** — 大部分队还在低级别对决,看热闹为主

### 战术安排

- **联赛**和**杯赛**在**同一周**(周二/四/三/六 都有比赛)
- **同一个阵容不可能 4 场全踢** — 体力(链 ch 4)+ 伤病
- **轮换**:联赛 1 场 + 杯赛 1 场 / 周,**至少 2 套阵容**
  - 周三 + 周六:**主力阵容**(联赛关键)
  - 周二 + 周四:**轮换阵容**(杯赛次要)
- 主力体能有问题时,联赛优先(影响积分榜),杯赛可以放

### 关键对手

- **R0-R1** — L4 队互相砍,跟你没关系
- **R2 之后** — L3 队进入,**小心低级别陷阱**(他们的 L1 队同 L2 队)
- **R6 之后** — L1 队进入,**真正的对手**
- **R10** — 4 强,通常 = L1 + L2 强队
- **R11** — 决赛,L1 vs L1 / L2 / L3 / L4(理论上任何队)

### 杯赛冠军 = 真成就

- **赢了全国杯 = 整个赛季最高成就**(跟 L1 联赛冠军比,杯赛冠军**更难** — 跨联赛 + 单淘汰)
- 球队详情页 / 球员详情页会有 `CHAMPIONSHIP_TITLE` 事件
- 玩家历史也会记一条

---

## 十四、跟球员事件的接口(链第 4 章)

杯赛冠军 = 球队级事件。**对球员**的影响:

| 杯赛结果 | 球员事件 |
|---|---|
| 球队夺冠 | 球员详情页记一条 `CHAMPIONSHIP_TITLE` |
| 球员决赛进球 | 未来可能记 `HAT_TRICK` / 进球记录(但 MVP 还没接) |
| 球员杯赛受伤 | 跟联赛受伤一样,`INJURY` 事件 |
