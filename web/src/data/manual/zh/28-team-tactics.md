# 比赛:球队战术

第 15 章讲的是 2 个维度(球场宽度 / 防线高度)。这一章讲**球队战术** —— 一个独立的选择:**从 5 个战术里挑 1 个,或者保持「常规」**。

球队战术和 2 个维度是两层东西,可以叠加:

- **2 个维度**是"旋钮":每一档只调一点点,可以随便组合
- **球队战术**是"路线":一个战术把整支球队的打法往一个方向整体推过去,代价是**排出 4 个指定的位置**

---

## 一、5 个战术(快速参考)

| 战术 | 要的 4 个位置 | 打法方向 | 一句话 |
|---|---|---|---|
| **传控压迫** | 中场 ×3 + 前腰**或**边路 ×1 | 短传为主,几乎不传中、几乎不远射 | 把球留在地上 |
| **高位逼抢** | 前腰**或**边路 ×2 + 中锋 ×1 + 中卫 ×1 | 传中 / 直塞 / 突破都有,逼抢更凶 | 把比赛推到对方半场 |
| **防守反击** | 中卫 ×2 + 边后卫 ×2 | 直塞 + 突破为主,进攻回合最少 | 让出球权,等机会 |
| **中路渗透** | 后腰 ×1 + 中场 ×2 + 前腰 ×1 | 直塞最多,传中几乎没有 | 从中路捅穿 |
| **双翼齐飞** | 边路 ×2 + 边后卫 ×2 | 传中最多,直塞最少 | 往边路拉开 |

> **「常规」也是一种选择**:不做任何安排 = 保持引擎的均衡打法。
>
> 排不出某个战术要的 4 个位置时,**你仍然可以先把它选上** —— 界面会立刻在卡片下面写明缺几个什么位置,但提交会被拦下来。所以选战术和配阵容没有先后顺序,两个 tab 之间可以来回调。

---

## 二、门槛是硬的

**每个战术要求上场的 11 人里,有 4 个位置落在指定范围内。** 这不是"满足越多效果越好",是**满足才生效**。选它不受限制,但**阵容不满足就提交不了** —— 界面会在卡片下面写明缺几个什么位置。

位置按**家族**算,不是按球员的"主位置"算 —— 看的是他**站的那个位置位**:

| 家族 | 包含的位置位 |
|---|---|
| 中卫 | CBL / CB / CBR |
| 边后卫 | LB / RB / LWB / RWB |
| 后腰 | DMFL / DMF / DMFR |
| 中场 | CML / CM / CMR |
| 前腰 | CAML / CAM / CAMR |
| 边路 | LM / RM / LW / RW |
| 中锋 | CFL / CF / CFR |

**几个容易踩的点:**

- 一个位置位只能算给一个要求。4 个要求必须落在 4 个不同的位置位上
- 门将不算进任何一个要求
- 边路家族里 **LM / RM 和 LW / RW 一样算**。传控压迫和双翼齐飞都接受 LM / RM
- **"前腰或边路"是并集**:高位逼抢要的那 2 个,可以两个都是前腰、两个都是边路,也可以各一个
- 你排的是一个**位置位**,不是球员。把一个 CM 拉到 LW 上,那个位置位算"边路",不算"中场"

**排不出来怎么办?** 照样可以选,但**提交会被拦**,卡片下面写明缺几个什么位置。系统不会帮你把战术降级成半档,也不会让部分要求生效 —— 要么补齐,要么换回「常规」。

## 三、五个战术逐个看

### 传控压迫

- **要**:中场 ×3 + (前腰 或 边路) ×1
- **打法**:进攻几乎全走**短传配合**。传中被压到很低,远射几乎消失
- **过程**:犯规比平常略少 —— 你的球员在处理球,不在抢球
- **适合**:中场人多的阵型(4-3-3 / 4-5-1 / 3-5-2),尤其你排得出 3 个中场的时候
- **代价**:进攻方式单一。如果你的短传路线打不动对方中路,你没有第二条路
- **强弱**:三条路的进攻和防守都略低,三条路的控球都略高 —— 用一点威胁换控球

### 高位逼抢

- **要**:(前腰 或 边路) ×2 + 中锋 ×1 + 中卫 ×1
- **打法**:逼抢强度更高,**犯规明显更多**;整队往前压一档,进攻和控球都略强一点,逼抢也更容易把球断下来
- **过程**:这是一套"用犯规换球权"的战术。你会比对手更频繁地把比赛打断
- **适合**:前场有活动能力、后场有一个能顶出来的中卫的阵型(4-2-3-1 / 4-3-3)
- **代价**:犯规多 = 送对方任意球、吃牌的风险更高。而且**整体上它比「常规」略吃亏** —— 犯规的代价大于逼抢换回来的那点进攻。选它是为了打法,不是为了变强
- **强弱**:三条路的进攻和控球都略高,三条路的防守都略低(整队压上,身后留空)

### 防守反击

- **要**:中卫 ×2 + 边后卫 ×2 —— 也就是一条完整的四人后卫线
- **打法**:**直塞和突破最多**的战术。控球被主动让出去,**进攻回合数反而是五个战术里最少的**
- **过程**:你不需要球权。抢下来之后一两脚就往前打 —— 后场站得稳的球队**断球也会明显更多**
- **适合**:五后卫 / 四后卫 + 双后腰的稳守阵型;对手控球强、压得高的时候
- **代价**:回合少,意味着**容错率低**。机会不多,抓不住就没有了
- **强弱**:三条路的防守都略高,三条路的控球都略低 —— 站得靠后,球权主动让出去

### 中路渗透

- **要**:后腰 ×1 + 中场 ×2 + 前腰 ×1
- **打法**:**传中几乎没有**,直塞是五个战术里最多的。所有进攻往中间挤
- **过程**:和"窄"的球场宽度是同一个方向,但更极端
- **适合**:中路堆人的阵型(4-1-2-1-2 / 3-5-2 的双前锋版),有两个能插上的中场
- **代价**:边路基本放弃。对方中路堆人时你没有 Plan B
- **强弱**:中路进攻和控球升、中路防守降;两条边正好反过来 —— 中路强,边路弱

### 双翼齐飞

- **要**:边路 ×2 + 边后卫 ×2
- **打法**:**传中最多**的战术,直塞最少。进攻往两条边拉
- **过程**:和"宽"的球场宽度是同一个方向
- **适合**:有正经边锋 + 进攻型边后卫的阵型(4-4-2 / 4-2-3-1 的边路版)
- **代价**:传中是转化率偏低的一种进攻方式 —— 你会得到很多次传中,但不一定换来进球
- **强弱**:两条边的进攻、控球、防守都升;中路三样都降 —— 两翼强,中路弱

## 四、战术动的是"三条路",不是一个总数

每个战术都不是"整体加一点",而是把球队强度在 **左路 / 中路 / 右路** 之间重新分配,每条路再分 **进攻 / 控球 / 防守** 三个面。

- **是"挪",不是"加"**:三条路的加权平均始终是 1。所以一个战术让你某条路变强,一定有别的路变弱 —— 你买到的是**方向**,不是**总量**
- **是球队层面的**:不会因为你的右边锋特别强,就在双翼齐飞里额外多给你一份。球员个人只在"这条路本来就是我这条边强"的意义上受益
- **看不见具体数值**:游戏不会告诉你"边路进攻 +x%"。你只能从打法(第三节)和比赛画面里判断

所以选战术时要问自己两个问题:**我想在哪条路、哪个环节上占便宜?我愿意让哪里吃亏?**

---

## 五、跟 2 个维度的关系

两层是**叠乘**的,不是二选一:

- **同方向** → 效果更强。比如"双翼齐飞 + 球场宽度宽",两条都在把进攻往边路推
- **反方向** → 互相抵消。比如"双翼齐飞 + 球场宽度窄" —— 战术在往边路拉,宽度在往中间收
- **不冲突** → 各管各的。防线高度跟这 5 个战术都不直接冲突

实用的搭配:

| 想要的画面 | 球队战术 | 2 个维度 |
|---|---|---|
| 稳控,不失误 | 传控压迫 | 窄 / 中 |
| 抢崩对手 | 高位逼抢 | 均衡 / 高 |
| 弱队打强队 | 防守反击 | 均衡 / 低 |
| 中路强攻 | 中路渗透 | 窄 / 高 |
| 边路压制 | 双翼齐飞 | 宽 / 中 |

## 六、五个战术一样强吗

**不一样,但差得很小。**

实测(同一套阵容自己打自己,每个战术上千场):传控压迫平均略微占优,高位逼抢平均略微吃亏,其余三个基本打平。这个差距**远小于**阵容、球员能力和 2 个维度带来的差距,而且它只比抽样误差大一点点 —— 你在一场比赛里几乎感觉不到。

所以选战术的出发点是"我想怎么踢",而不是"哪个更强"。真正的成本是第二节说的那件事:**你要拿 4 个位置位去换。**

---

## 七、常见错误

- **以为门槛是"越多越好"** —— 不是。正好 4 个位置位,多出来的位置位不给你任何额外收益
- **以为可以"降级"** —— 不满足就是不能选,没有半档
- **按球员主位置凑门槛** —— 门槛看的是**位置位**。把一个 CM 拉到 LW 上,他占的是边路的位置位
- **忘了边路包含 LM / RM** —— 只有边锋的队也能排双翼齐飞
- **把高位逼抢当成"进攻战术"** —— 它买的是逼抢和断球,代价是犯规。整队进攻只强一点点,但犯规的代价更大
- **选完战术又改阵型** —— 改了阵型可能把 4 个位置位拆散,战术就部署不了。改完阵型请重新确认

---

## 八、跟其他概念的关系

- **跟宽度 / 防线**:叠加,见第五节
- **跟替补**:球队战术作用在**整支球队**上,换人不影响它生效。但**位置挪动可能拆掉门槛** —— 把唯一的中场挪去边路,门槛就不满足了
- **跟球员能力**:门槛不看球员强不强,只看你**位置排得对不对**。战术带来的强弱变化**按左/中/右三条路分配**,也不看具体球员 —— 它不会因为"我的边锋特别强"而在双翼齐飞里多给你一份收益(见第四节)
- **跟特长**:两套系统独立。特长挂球员,球队战术挂球队
