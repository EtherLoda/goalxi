# 球员等级标签

GoalXI 用一套 **21 档 tier 标签** 把技能和经验等级的 0-20 数值"翻译"成人类可读的名字。这套标签在**多个地方共用**,所有引用本附录的章节都拿同一份表。

## 哪些地方用这套标签

- **技能** — 雷达图上每项技能 0-20 → 一个 tier 标签(技能面板、球员卡)
- **经验** — 球员累计 XP 算等级 → 一个 tier 标签(经验 badge)
- **位置强度**(未来) — 部分强度指标可能也用

> 简而言之:**雷达图 / 球员卡 / 经验 badge 看到的标签,都是这张表**。

## 怎么读

### 技能(0-20 → L0-L20 直接映射)

雷达图上每项技能旁边都标一个标签:

- `pace 18` = `L18 登峰造极`
- `dribbling 12` = `L12 顶尖`
- `defending 5` = `L5 合格`

每项技能**独立**映射(不综合)。**一个 pace 18 + dribbling 6 的 W 比 pace 6 + dribbling 18 的 W 强**,因为 W 的头牌是 pace + dribbling 都高。

### 经验(累计 XP → L0-L20,**L20 封顶显示**)

经验按累计值映射,但**显示在 L20 就封顶** —— 内部等级还能继续涨(没有上限),但 tier 标签不会超过 `L20 化境`。

所以你看到 L20 的老将,实际经验可能差距很大(从刚到 L20 到 L30+),但**全部显示同一个标签**。区分老将之间的"老练度"看原始 XP,不是 tier 标签。

**鼠标悬停**在 tier 标签上,通常会显示原始数值(技能 18 / XP 162 等)。

---

## 跨标签对比

- 同一个球员,**技能 L12 + 经验 L20** 不矛盾 —— 是**两个独立维度**的标签
- **技能 L20 不等于强** —— 还要看头牌是不是对位置
- **经验 L20 不等于稳** —— 还要看具体技能和位置
- 两个球员都标 L18 登峰造极,**一个可能是 pace 18 + 其他平庸,另一个可能是 pace 18 + dribbling 18 + finishing 16** —— L18 只说明这一项达标

## 跟其他概念的关系

| 概念 | 关系 |
|---|---|
| **技能**(第 2 章) | 技能 0-20 → 标签,每项独立 |
| **PWI / overall**(第 4 章) | 头牌技能 + 潜力 + form 综合算,**不是** tier 标签 |
| **经验 / 等级**(第 4 章) | 累计 XP → 标签,L20 封顶 |
| **位置**(第 3 章) | 头牌技能 + 位置 = 球员对球队的价值,**不是** tier 标签 |
| **潜力 potentialTier**(第 4 章) | 5 档(LOW / REGULAR / HIGH_PRO / ELITE / LEGEND),**和 21 档 tier 标签是两套不同的系统**,别混 |

> `potentialTier` 是 5 档的"潜力档",`tier label` 是 21 档的"当前技能/经验档",名字像但**不是同一套**。

---

## 常见错误

❌ **把 21 档标签当 PWI 用**:L18 登峰造极 ≠ 强球员,要看 PWI
❌ **跨维度比标签**:技能 L12 + 经验 L20 ≠ 综合分,要分开看
❌ **"L20 = 满级"**:L20 是显示上限,实际等级还能继续涨
❌ **"L0 = 0"**:L0 标签是 "无",意思是"没数据",不是真的"0 数值"(正常球员最低 L1 糟糕)
❌ **跟 potentialTier 混**:5 档潜力 ≠ 21 档 tier,两套系统
❌ **技能标签只挑最高的看**:每项独立,要看全部 10/9 项,不只是头牌
