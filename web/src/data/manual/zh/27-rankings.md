# 球队排名

GoalXI 的"排名"目前**只有 3 个维度的公开榜单**,都是**按联赛分**的(没有跨联赛的"全国排名")。**全球射手榜 / 跨联赛球队榜 / 转会活跃榜 / 球迷榜 都没有**。

这一章讲**3 个有的是哪个、怎么用、什么时候看**,以及**没做的是哪些**(避免玩家白找)。

---

## 一、3 个有 + 4 个没有(快速参考)

| 排名 | 有吗? | 端点 | 说明 |
|---|---|---|---|
| **联赛积分榜**(每联赛 16 队) | ✅ | `GET /leagues/:id/standings?season=N` | 链 ch 20 |
| **联赛球员榜**(进球 / 助攻 / 抢断) | ✅ | `GET /stats/leaderboard/:leagueId/:type?season=N&limit=10` | 每联赛一份,前 10 |
| **球队赛季统计**(单球队数据) | ✅ | `GET /stats/teams/:teamId/season/:season` | 不是榜单,是单球队聚合 |
| **全球球队排名** | ❌ | — | MVP 阶段没做 |
| **全球射手榜 / 助攻榜 / 抢断榜** | ❌ | — | 只有联赛内,没跨联赛汇总 |
| **转会活跃榜** | ❌ | — | MVP 阶段没做 |
| **球迷榜** | ❌ | — | 只有 `GET /teams/:teamId/fans`(查自己球队粉丝),没排名 |

> **MVP 阶段重点**:你**只能在自己联赛内**比,**不能跨联赛**看"L1 哪支队最强"或"L4 哪个球员进球最多"。

---

## 二、联赛积分榜(最常用)

**端点**:`GET /leagues/:id/standings?season=N`(公开,`@Public()`)

**每联赛一份**,赛季 1 起,默认 `season=1`。MVP 阶段每联赛 16 队,所以**每份榜单 16 行**。

### 字段

| 字段 | 含义 |
|---|---|
| `position` | 排名(1 = 榜首) |
| `teamId` / `teamName` | 球队 id / 名字(动态 join) |
| `played` | 已赛场次 |
| `wins` / `draws` / `losses` | 胜 / 平 / 负场次 |
| `goalsFor` | 进球数 |
| `goalsAgainst` | 失球数 |
| `goalDifference` | 净胜球(**进球 - 失球**,在服务层计算) |
| `points` | 积分(胜 3 / 平 1 / 负 0) |
| `recentMatches` | 最近 5 场(W / D / L + 比分 + 对手,**动态算**) |

### 排序规则(DB 层就排好)

```
points (高 → 低)
   ↓ 同分
goalDifference (高 → 低)
   ↓ 同分
goalsFor (高 → 低)
```

> 净胜球比进球数重要 — 5-0 赢 > 4-0 赢(同样进 4,5-0 净胜球更高)。

### 怎么看

- **榜首争夺** = 前 2 名,通常赛季末几周定冠
- **保级 / 升级** = 9-12 附加赛区,13+ 降级区(链 ch 20)
- **看最近状态** = `recentMatches` 数组(W / D / L 链起来看)
- **看对手** = `teamName` 字段知道是谁

### 什么时候看

- **赛季初** — 看 1 次,知道谁在第一梯队
- **赛季中** — 每周 1-2 次,关注**积分 + 净胜球**(同分决定排名)
- **赛季末** — 每天,看 9-12 名(升降级线)
- **你的球队** — 比赛结束后马上看自己的位置变化

## 三、球员榜(联赛内)

**端点**:`GET /stats/leaderboard/:leagueId/:type?season=N&limit=10`(公开)

**3 种 type**:
- `goals` — 进球榜
- `assists` — 助攻榜
- `tackles` — 抢断榜

### 字段(每条)

| 字段 | 含义 |
|---|---|
| `playerId` / `playerName` | 球员 id / 名字 |
| `teamId` / `teamName` | 球队 id / 名字 |
| `goals` / `assists` / `tackles` | 该项数据(按 type 排) |
| `yellowCards` / `redCards` | 黄 / 红牌数(参考) |
| `appearances` / `starts` | 出场 / 首发数 |

### 排序

- 按 `type` 对应字段降序(进球多 > 进球少)
- 同分 tiebreaker:`playerId` 升序(稳定的次级排序,不是名字)

### 限制

- **只看本联赛** — 不能看"L1 联赛谁进球最多"或"全部联赛合并"
- **limit 默认 10** — 16 队联赛里**只显示前 10**,后 6 名不显示
- **`offset` 支持** — 翻页拿 11-20 名?MVP 阶段每联赛就 16 队,前 10 已经够看;offset 主要是 API 层面留的口子
- **没**球员头像 / 球队 logo URL(就纯文字)

### 跟球员个人战绩的关系

- **球员榜** = **本联赛**所有球队所有球员的汇总(排行)
- **球员详情页**(链 ch 4) = 自己的完整数据(联赛 + 杯赛 + 国家队,全赛季)
- **球员详情页 = 球员的"个人报告"**,**球员榜 = 全联赛的"排行榜"**

## 四、单球队赛季统计(辅助)

**端点**:`GET /stats/teams/:teamId/season/:season`(公开)

> 这**不是榜单**,是**单球队的赛季聚合数据**。放在 ch 27 因为也是"赛季统计"。

| 字段 | 含义 |
|---|---|
| `teamId` | 球队 id |
| `matchesPlayed` | 已踢场次(只算 COMPLETED 的) |
| `wins` / `draws` / `losses` | 胜 / 平 / 负 |
| `goalsFor` / `goalsAgainst` | 进 / 失球 |
| `goalDifference` | 净胜球 |
| `points` | 积分 |
| `cleanSheets` | **零封场次**(0 失球,守门员友好) |

> 这是从 `match` 表里**实时聚合**(没有缓存)。所以**只算 COMPLETED 的比赛**,**杯赛不算**(只算 `matchType='LEAGUE'`)。

## 五、什么时候看哪种

| 你想看什么 | 用哪个 |
|---|---|
| 我在联赛排第几 | 联赛积分榜(自看 position) |
| 哪些队是直接对手 | 联赛积分榜前 8 名 |
| 谁是联赛最佳射手 | `/stats/leaderboard/:leagueId/goals?limit=10` |
| 谁是联赛助攻王 | `/stats/leaderboard/:leagueId/assists?limit=10` |
| 谁是联赛抢断王 | `/stats/leaderboard/:leagueId/tackles?limit=10` |
| 我的球队本赛季战绩 | `/stats/teams/:myTeamId/season/N` |
| 谁进了 L1 国家杯 4 强 | ❌ 没有(看 cup bracket,链 ch 21) |
| L1 哪支队最强 | ❌ 没有(MVP 阶段没做跨联赛排名) |
| 谁是 MVP 候选 | ❌ 没有(没有 MVP 奖) |
| 我队最受欢迎 | ❌ 没有(球迷详情查自己球队,没排名) |

## 六、没做的(用户需求 vs MVP 状态)

Hattrick 有**很多种排名**:
- 全球球队排名(按 ELO)
- 各国联赛排名
- 转会收入榜
- 球迷数榜
- 历史最佳战绩
- 等等

**GoalXI MVP 阶段只做了跟"赛季进程"直接相关的 3 个**(积分榜 / 球员榜 / 单队统计),其他**全部没做**。

### 未来可能加(MVP 之后)

| 排名 | 优先级 | 说明 |
|---|---|---|
| **跨联赛球队排名** | 高 | 按 ELO / 战绩汇总 85 联赛 |
| **跨联赛射手榜** | 中 | 跟联赛射手榜类似,但汇总 1360 队所有球员 |
| **转会活跃榜** | 低 | 卖 / 买频率最高的球队,商业向 |
| **球迷数榜** | 低 | 装饰性,跟游戏机制关系不大 |
| **历史最佳战绩** | 中 | 跨赛季查询 |
| **球员个人奖项** | 高 | 金靴 / 助攻王 / 最佳门将(联赛 + 杯赛) |

> 这些**当前都不在 MVP 范围**,玩家反馈需求后再排期。

## 七、跟其他概念的关系

| 概念 | 关系 |
|---|---|
| **联赛**(第 20 章) | 积分榜就是联赛的核心展示 |
| **杯赛**(第 21 章) | 杯赛**没**排名(单淘汰),但 bracket 类似一个"树形榜" |
| **球员**(第 4 章) | 球员详情页 = 个人报告,球员榜 = 全联赛排行 |
| **转会**(第 18 章) | 球员榜**不**显示"刚从转会来的球员高亮" |
| **特性**(第 4 章) | 球员榜**不**显示"X 特性加成"的细分(全联赛汇总,不分特性) |
| **青年**(第 19 章) | 青年球员**可以**上球员榜(如果踢联赛) |

## 八、能做 / 不能做

### ✅ 能做

- 看自己联赛的积分榜(随时)
- 看自己联赛的球员榜(进球 / 助攻 / 抢断,前 10)
- 看自己球队的赛季聚合数据
- 看历史赛季的积分榜(`?season=N`)

### ❌ 不能做(MVP 阶段)

- **跨联赛排名** — 看不到"L1 哪支队最强"
- **跨联赛球员榜** — 看不到"L1 + L2 + L3 + L4 进球最多"
- **球队页的"我的位置"显示在跨联赛榜第几** — 没有
- **粉丝数排名** — 看不到
- **球员个人奖项** — 金靴 / 助攻王 等**不单独设奖**,只在球员详情页记一条 `GOLDEN_BOOT` 事件(链 ch 4)
- **未来赛季预测** — 不能
- **球队历史汇总** — MVP 阶段没做(只能看当季)

### ❌ FE 限制(也是 MVP)

- 球员榜**只显示前 10**,后 6 名(假设 16 队联赛)**不显示**
- 球员榜**没头像**(纯文字)
- 球队数据**没图表**(没进球趋势、没胜负曲线)
- 跨赛季筛选**支持**(用 `?season=N`),但**跨联赛筛选**不支持

## 九、常见错误(关于排名)

❌ **"积分榜 = 冠军榜"**:积分榜只反映**当季**,不能跨赛季;**冠军是 L1 联赛冠军 + National Cup 冠军**,不是积分榜常客
❌ **"球员榜前 10 = 全部球员"**:默认 `limit=10`,**后 6 名(16 队联赛)看不到**;要全榜要 offset 翻
❌ **"我能看到 L1 球员"**:不能。**只能看自己联赛**(以及看自己球队,看自己球员)
❌ **"球员榜跨联赛"**:**不能**,每联赛一份独立榜单
❌ **"cleanSheets = 门将评分"**:cleanSheets 是**场次**(没失球),不是评分;门将评分**没单独的公开榜**
❌ **"进球数 = 球队进球数"**:球员榜是**球员个人**进球,**不是球队**进球;球队进球数从单队统计拿
❌ **"排行榜能买 / 卖"**:排行榜**只读**,不能通过榜单操作球员(链 ch 18 的转会)
❌ **"球迷榜能涨工资"**:**没有球迷榜**,也不通过排名涨工资
❌ **"金靴奖 = MVP"**:MVP 阶段**没**金靴奖,**没** MVP 奖;**只有** `GOLDEN_BOOT` 事件(链 ch 4 + `player-event-types` FAQ)

## 十、实战流程(球队经理视角)

### 你的赛季看榜节奏

| 时段 | 看什么 | 频率 |
|---|---|---|
| **周一** | 球员榜(看新星冒头没) | 1 次 / 周 |
| **周三** | 自己的联赛积分榜(刚踢完联赛) | 每次联赛后 |
| **周五** | 球员榜(进球 / 助攻) | 1 次 / 周 |
| **赛季末** | 积分榜前 8 + 9-12 升降级区 | 每天 |

### 怎么用球员榜

- **选秀 / 买人** — 看对方联赛球员榜,挑**进球多 / 助攻多**的(链 ch 18 `comparing-two-players`)
- **战术调整** — 你队**助攻王** = 组织核心,**别卖**;**抢断王** = 中场铁闸,**别卖**
- **挖角** — 其他队球员榜前 10 = 你的目标,看**自己能不能买得起**(链 ch 18)

### 怎么用积分榜

- **前 4 名** = 直接竞争对手,**重点研究**他们的 PWI / 战术 / 状态
- **5-8 名** = 中游
- **9-12 名** = **附加赛直接对手**,赛季末每场都重要
- **13+ 名** = 你的"提款机",赢他们拿净胜球

### 跟对手的"看榜技巧"

- **看进球**:对方**前 3 射手** vs 你的**后防核心**,哪边强?
- **看助攻**:对方**前 3 助攻手** 是边路 / 中场 / 哪个位置?你的对应位要防
- **看抢断**:对方**抢断王** = 中场铁闸,你要是攻不破就输
- **看零封**:对方**零封场次**多 = 防线稳,你需要靠远射 / 任意球破密集
