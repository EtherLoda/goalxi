# 转会交易

转会市场 = **球员挂牌** + **拍卖** + **成交结算** 三件事的组合。**买人**和**卖人**都在这里完成。

这一章讲**怎么挂牌、怎么出价、拍卖怎么走、成交后发生什么**,以及**目前能做什么 / 不能做什么**。买人前要看哪些属性(伤病 / form / 经验 / 头牌 / 潜力 / 28+ 衰退)详见 [第 4 章](04-player-attributes.md)和 `comparing-two-players` FAQ 条目。

---

## 一、2 种挂牌方式

**GoalXI 有 2 种方式把球员推到转会市场**,作用不同:

| 方式 | 做什么 | 有没有出价机制 | 适合 |
|---|---|---|---|
| **快速挂牌**(quick list) | 把球员标成 `onTransfer = true`,**不设价格** | ❌ 没有人能出价 | 探价 / "我可能卖"信号 |
| **拍卖**(auction) | 创建拍卖,设**起拍价 + 立即成交价 + 持续时间** | ✅ 其他队可出价,到点结束 | **正式卖人** |

**关键区别**:
- 快速挂牌 = **没有具体价格**,其他队**看不到**出价按钮,只能"询价"(目前没有询价 UI)
- 拍卖 = 有具体价格,其他队可以正式出价
- 拍卖**不取消**就到点结束,**不能中途撤销**(防止卖方反复横跳)
- **一个球员同一时间只能在一个拍卖里** — 同一球员有 ACTIVE 拍卖时,不能再开新的

> **实战常用**:**直接拍卖**。快速挂牌在当前版本几乎没用(没询价 UI),玩家用得少。

## 二、作为卖家 — 怎么卖

### 创建拍卖

要拍卖的球员**必须在你的球队里**(不是 youth,不是对手)。调用 `POST /transfer/auction`:

| 字段 | 必填 | 含义 | 典型值 |
|---|---|---|---|
| `playerId` | ✅ | 你的球员 id | — |
| `startPrice` | ✅ | 起拍价(第一个 bid 必须 ≥ 这个数) | **自己设**(没有"PWI 自动算价"的公式,链 ch 4) |
| `buyoutPrice` | ✅ | 立即成交价 | **必须 > `startPrice`**(后端强校验) |
| `durationHours` | ❌ | 拍卖持续时间 | 默认 **1 小时** |

> **重要事实**:
> - **起拍价 / 立即成交价都是你手动设的**,引擎不帮你算 PWI → 价格
> - 工资(`currentWage`)**不会因为转会自动调整** — generation 时定,转手后保持不变
> - **没手续费** — 成交价 100% 给你

### 拍卖创建后

- 球员 `onTransfer` 标志自动置为 `true`,直到拍卖结束 / 取消
- 球员**仍然在你的球队**,但其他队能在转会市场看到 + 出价
- 球员**仍能上场比赛** — 拍卖不影响上场

### 拍卖期间(卖家)

卖家在拍卖期间能看到的:
- **`GET /transfer/auction/my-listings`** — 我挂的所有拍卖
- 当前价 / 当前最高出价者(只有"team"显示,**不显示**具体队名之外的细节)
- **bid history**(完整出价记录,包括自己之前的出价)
- 倒计时(系统每分钟 cron 扫一次)

卖家在拍卖期间**不能**:
- ❌ 取消拍卖(到点自然结束 / 或过期作废)
- ❌ 改价(起拍价 / 立即成交价都锁死)
- ❌ 提前结束拍卖

## 三、作为买家 — 怎么买

### 进入拍卖

**`GET /transfer/auction`** 列出当前**所有进行中的拍卖**(ACTIVE + SETTLING)。每个拍卖有:
- 球员信息(技能 / PWI / 潜力 / 特性 / 年龄 / 伤病,详见 [第 4 章](04-player-attributes.md))
- 当前价 / 起拍价 / 立即成交价
- 当前最高出价者(显示队名)
- **倒计时**(可能因为最后 3 分钟出价而延长,见下文)
- 出价历史

### 怎么出价

`POST /transfer/auction/:id/bid` with `amount`:
- **首次出价** = ≥ `startPrice`
- **后续出价** = ≥ `currentPrice + minIncrement`
- **minIncrement** = `max(10 000, currentPrice 的 5%)`(取绝对下限和 5% 比例两者中较大的)
  - 例:当前 100,000 → 下次至少 105,000(5% 大)
  - 例:当前 50,000 → 下次至少 60,000(10 000 绝对下限)
  - 例:当前 200,000 → 下次至少 210,000

**实际扣款时序**:
- 出价时,**不是**直接从账户扣钱,而是**锁定**(`lockedCash += amount`,可用的钱 = 余额 - 锁定中)
- 你**输了**(被超价):锁定解除,钱回账户
- 你**赢了**(成交):锁定 → 实际扣款,转到卖家

> **优点**:你出价后还能用剩下的钱做别的事(出价没真扣,只是冻住)
> **风险**:账户冻结总额 ≥ 余额时,下次出价会被后端拒("Insufficient funds")

### 买自己队的人 ❌

后端校验:你**不能**给你自己球队挂的拍卖出价(防止"自卖自买"洗钱)。返回 400。

### 最后 3 分钟延长

**Hattrick 式 last-minute extend**:
- 拍卖**最后 3 分钟**内有人出价 → 自动延长 3 分钟
- 反复触发 — 每次最后 3 分钟出价都会重新延长
- 直到**没人再出价**或达到下次延长前的窗口

> 目的:防止"最后一秒狙击"(快结束前才出价抢走)。晚 3 分钟内出价,卖家有更多时间反应。

### 出价后看到什么

- **当前出价者 = 你** → 你领先
- **当前出价者 ≠ 你,但你出价过** → **被超价**(`isOutbid = true`)。可以**再出价**(拿回来)
- **当前出价者 ≠ 你,你没出价过** → 别人领先,你可以**首次出价**
- **`GET /transfer/auction/my-bids`** — 你出过价的所有拍卖 + 领先/被超价状态

### 立即成交(buyout)

> **当前版本 disabled**。`auction.constants.ts:13` `BUYOUT_ENABLED: false`
>
> 立即成交的**数据层(列 / DTO / 拍卖行)** 都还在(为未来重新启用),只是**没 API 端点接**。要等 buyout UI 准备好才打开。
>
> 现在的"立即成交"只能**等拍卖自然结束**。

## 四、拍卖生命周期(状态机)

每个拍卖有 5 个状态(`AuctionStatus`):

```
ACTIVE ───(到期 / 取消)──→ EXPIRED / CANCELLED
   │
   ├──(到点 + 有中标)──→ SETTLING ──(结算 worker)──→ SOLD
   │
   └──(到点 + 没人出价)──→ EXPIRED
```

| 状态 | 含义 | 你能做什么 |
|---|---|---|
| **ACTIVE** | 进行中,可以出价 | 买家出价 / 卖家等 |
| **SETTLING** | 到点了,有中标,**结算 worker 正在处理** | 等(通常几秒到几十分钟) |
| **SOLD** | 成交 — 球员已转到买家队 | 看成交记录 / 玩家历史 |
| **EXPIRED** | 到点**没人出价** — 流拍 | 球员 `onTransfer = false`,重新可用 |
| **CANCELLED** | (目前不用,保留供未来) | — |

**SETTLING → SOLD 的细节**:
- 每分钟 cron 扫 ACTIVE 拍卖,挑出过期的(最多 500/批,8 并行)
- 结算 worker 在事务里:
  1. 创建 `TransferTransaction` 记录(`AUCTION_COMPLETE` / `PENDING` → `PROCESSING` → `COMPLETED`)
  2. 把球员 `teamId` 改成买家
  3. 解锁买家 `lockedCash`(已经从冻结变真扣)
  4. 给卖家账户加钱
  5. 写球员事件 `TRANSFER`
- **如果 worker 挂了**(中途崩溃),有恢复 cron 每 5 分钟扫 SETTLING 超时 10 分钟的,重新入队
- **前端看到**:SETTLING 期间 FE 还是显示拍卖(等成交),1-2 分钟后变 SOLD(球员到新队)

## 五、成交后看什么

### 交易记录

- **`GET /transfer/transactions/purchases`** — 你买的人
- **`GET /transfer/transactions/sales`** — 你卖的人
- 每条 `TransferTransaction`:
  - 类型:`AUCTION_COMPLETE`(目前只有这一种,`BUYOUT` 是 disabled 状态下保留的)
  - 状态:`PENDING` / `PROCESSING` / `COMPLETED` / `FAILED`
  - 金额:成交价
  - 买卖双方队
  - 赛季 / 周

### 球员事件历史

- 球员详情页 → Events 区域会有一条 `TRANSFER` 事件
- 跟 `HAT_TRICK` / `GOLDEN_BOOT` 等成就事件并排(链 ch 4 `player-event-types` FAQ)
- 记录的是"何时转到新队",不记拍卖过程

### 财政影响(链 [第 9 章](09-finance.md))

- **买人** = 钱从你账户到卖家账户(`TRANSFER_OUT` 支出,`TRANSFER_IN` 收入给卖家)
- **球员的 `currentWage` 不会变** — generation 时定的工资,转手后保持不变
- 没手续费

## 六、目前能做什么 / 不能做什么

### ✅ 能做

- 把任意你球队的 senior 球员标成 `onTransfer`(快速挂牌,无价)
- 创建拍卖(起拍价 / 立即成交价 / 时长)
- 拍卖期间多次出价(被超价可以再来)
- 最后 3 分钟延长(Hattrick 式)
- 出价时锁定现金,不真扣
- 跨队询价(其他队的拍卖)
- 成交后看 transactions / 球员 TRANSFER 事件

### ❌ 目前不能 / 没实现

- **立即成交(buyout)** — `BUYOUT_ENABLED: false`,数据列还在但端点没接
- **合同续约(player contract renewal)** — `CONTRACT_RENEWAL` 是球员事件**类型定义**,但**没有任何 API 端点生成这个事件**;球员工资是 generation 时定,转手后保持不变
- **中止拍卖** — 拍卖开始后不能撤(到点自然结束)
- **询价 / 议价** — 快速挂牌后没 UI 问"多少钱卖"
- **跨联赛转会** — 当前只支持同联赛内(`TODO` 状态,未来版本)
- **球员 vs 球员交换** — 没实现
- **租借** — 没实现
- **现金不够时借贷** — 没实现,账户余额不足直接拒
- **税 / 手续费** — 没有,100% 成交价归卖家

### youth 球员的"释放"(区别于挂牌)

- youth 球员**不能**直接走拍卖
- 走专门的 `POST /players/:id/release` 端点(soft-delete,链 [第 4 章](04-player-attributes.md))
- 释放后球员从队里消失,但**记录保留**(链 ch 4)

## 七、怎么定价(卖家角度)

GoalXI **没有"PWI → 价格"的自动公式**(链 [第 4 章](04-player-attributes.md))。你自己设。

### 参考定价框架(不是公式,是经验)

| 球员 | 起拍价参考 | 立即成交价参考 |
|---|---|---|
| **替补** (PWI 8-10) | 5 000 - 20 000 | 20 000 - 50 000 |
| **主力** (PWI 12-14) | 50 000 - 150 000 | 200 000 - 500 000 |
| **头牌** (PWI 15+) | 200 000 起 | 500 000 起 |
| **新手** (PWI < 8) | 1 000 - 5 000 | 5 000 - 20 000 |

> 这些是**经验范围**,不是引擎强制的。你**想卖多少卖多少**,可能没人买。
> 工资(`currentWage`)**不影响**成交价(链 ch 4)。

### 怎么挂(自己决定)

- **想快卖** → 起拍价贴近市场参考下界,买的人多但卖得便宜
- **想卖高价** → 起拍价高,可能流拍(没人出价 → EXPIRED)
- **保险** → 立即成交价 = 起拍价的 2-3 倍,允许"加价过快"的买家直接成交(但当前 buyout 端点未开,这个保险暂时不生效)
- **可接受最低** = 你的**心理底价**,如果起拍价低于这个,大概率流拍

## 八、怎么买(买家角度)

**见** `comparing-two-players` FAQ 条目(11 个维度,头牌 / 潜力 / 伤病 / form / 经验 / 工资 / 28+ 衰退 / 特性匹配 / 价格 等)。

### 实战流程

1. **进 `/transfers`** — 看到所有 ACTIVE + SETTLING 拍卖
2. **筛选** — 按位置(PWI / 头牌 / 年龄 / 特性)过滤
3. **选 1-2 个候选** — 同位置对比(`comparing-two-players`)
4. **看伤病 / form / 经验** — 短期的即战力 vs 长期价值
5. **看出价历史** — 是不是被炒上去的(多人争抢 → 价格虚高)
6. **出价**:
   - **市场价** → 拍起拍价 + 一点点
   - **必拿** → 直接打到立即成交价(等 1 小时)
   - **捡漏** → 拍卖**最后 1-2 分钟**才出价(但有 last-minute extend,别人出价就延长,你还有窗口)
7. **被超价?** — 看你想不想要,**再出**或者放手
8. **成交** — 等 1-2 分钟 SETTLING,球员到你队

### 出价策略(实战)

- **冷门球员** → 拍起拍价就够(没人跟你争)
- **热门球员** → 提前出价,逼别人加价
- **最后 1 分钟** → 出价,等 3 分钟延长(给你时间看其他队会不会跟)
- **不要预算吃紧** → 锁定金额过高,可能错过其他出价机会

## 九、实战常见错误

❌ **"设了起拍价就有人买"**:**没人买就流拍**(`EXPIRED`),起拍价太高的话卖不掉
❌ **"立即成交价 = 必卖价"**:当前**没 buyout 端点**,立即成交价**不生效**,只能等拍卖自然结束
❌ **"出价后钱就扣了"**:出价是**锁定**(`lockedCash`),不是真扣。被超价会**自动解冻**
❌ **"拍卖到点自动成"**:到点**不**自动成,worker 每分钟扫一次,SETTLING 1-2 分钟才到 SOLD
❌ **"可以提前结束拍卖"**:**不能**。开始到结束只能等
❌ **"挂了就一直挂着"**:**不会**。流拍后 `onTransfer = false`,球员重新可用
❌ **"出价了 = 一定买得到"**:可能被超价,看 `my-bids` 看是否领先
❌ **"跨队买 = 找对方私聊"**:全部走 `/transfers`,**没**私信 / 议价
❌ **"高 PWI = 高成交价"**:**没必然**。PWI 高的挂牌**可能**定得高(卖家心理),但 PWI 跟成交价**没有自动公式**
❌ **"工资跟着转会变"**:**不变**。工资 generation 时定,转手后保持
❌ **"立即成交价是保底"**:**当前 disabled**,保底是"卖 0 元"流拍
❌ **"快速挂牌就有人来问"**:**没询价 UI**,快速挂牌目前**几乎没用**

## 十、怎么用转会(总览)

### 卖人 4 步

1. 选你要卖的球员(同位置有替补再卖,链 ch 5)
2. 决定价格(参考第 7 节)
3. 创建拍卖
4. 等 1 小时(或更久,last-minute extend),看 `my-listings` 跟 `transactions/sales`

### 买人 4 步

1. 跟教练 / scout 确认**你需要什么位置 + 头牌**
2. 筛 `/transfers`,看 1-2 个候选
3. 用 `comparing-two-players` 框架对比
4. 出价(分冷门 / 热门 / 捡漏 3 种策略,见第 8 节)

### 何时卖

- **赛季初** — 阵容大换血,挂牌多
- **赛季中** — 替补边缘人 / 工资高的老将(28+ 衰退),趁还能卖上价出
- **不要**:**首发的头牌不要卖**,除非有非常明确的重建计划

### 何时买

- **赛季初** — 补强,预算足,可选多
- **赛季中** — 补伤 / 补状态,**看准再买**(买来不能马上用就亏)
- **赛季末** — 不建议,价格虚高(其他队也在补)

## 跟其他概念的关系

| 概念 | 关系 |
|---|---|
| **球员属性**(第 4 章) | 买人看 PWI / 头牌 / 伤病 / form / 经验 / 28+ 衰退 / 工资(都是同位置对比的输入) |
| **阵容**(第 5 章) | 卖人前**确保有同位置替补**,否则阵容就空一个 |
| **财政**(第 9 章) | 交易 → 现金进出 + 工资持久(转手后工资不变) |
| **球员事件历史**(`player-event-types` 条目) | 成交后球员详情页记一条 `TRANSFER` |
| **青年球员** | 走专门的 `release` 端点(链 ch 4),**不走拍卖** |
| **球探** | 球探是**补充**,不是**替代** — 球探的候选会进 `onTransfer = false` 的池子,需要再挂牌才能拍卖 |
