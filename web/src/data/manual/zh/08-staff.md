# 教练

教练(也叫 staff)负责训练你的球员、恢复他们的体能、加速伤病恢复。这章讲教练**怎么请、怎么升级、怎么解约、多少钱**。

> 训练机制本身(怎么分配、怎么练)见 [第 7 章](07-training.md)。伤病怎么治见 [第 4 章](04-player-attributes.md)。教练工资对预算的压力见 [第 9 章:财政](09-finance.md)。

---

## 5 个等级(教练有强弱)

每个教练有 **5 档等级**:**Lv.1 → Lv.5**。

| 等级 | 角色 | 训练加成 | 周薪(参考) |
|---|---|---|---|
| **Lv.1** | 入门 | 最低 | 500 |
| **Lv.2** | 初级 | 较低 | 2,000 |
| **Lv.3** | 中等 | 中 | 8,000 |
| **Lv.4** | 高级 | 较高 | 32,000 |
| **Lv.5** | 顶级 | 最高 | 128,000 |

**关键事实**:
- 等级越高,**训练加成越大**(具体加成见 [第 7 章](07-training.md))
- 等级越高,**周薪越贵**(每一级约 4 倍)
- **不能直接"升级"教练**——想换等级,要**解约 + 重新签**

---

## 7 种教练(岗位)

| 岗位 | 作用 | 数量限制 |
|---|---|---|
| **主教练** | 全队训练基础加成 | 1 个 |
| **体能教练** | 体能恢复加成 | 1 个 |
| **技术教练** | 训练 4 项技能:射门 / 传球 / 盘带 / 防守 | 最多 2 个专项(总数) |
| **心理教练** | 训练 2 项技能:跑位 / 沉着 | ↑ |
| **定位球教练** | 训练 2 项技能:任意球 / 点球 | ↑ |
| **门将教练** | 训练 3 项门将技能:反应 / 扑救 / 高空球 | ↑ |
| **队医** | 加速伤病恢复 | 1 个 |

**岗位核心规则**:
- **每个岗位最多 1 个**(主教练 / 体能教练 / 队医 都是)
- **专项教练(技术 / 心理 / 定位球 / 门将)总数 ≤ 2**——你最多只能同时养 2 个专项教练
- 已经有了 2 个专项 → 不能再签第 3 个,得先解约一个
- 队医独立,**不占专项教练名额**

## 招聘(签约)

进入训练场 → "签约专项教练" / "签约体能教练"。

**步骤**:
1. 选岗位
2. 选等级(Lv.1 - Lv.5)
3. (专项教练)选主训技能
4. 看到**签约费 + 周薪**预览
5. 确认 → 扣现金 → 教练生效

**规则**:
- 该岗位已有有效教练 → **不能签**(要先解约旧的)
- 专项教练总数已满(2 个)→ 不能签第三个
- **现金不够** → 系统拒绝("余额不足")
- 签完立即**扣签约费**(一次性)+ 开始**按周扣周薪**

---

## 解约(解雇)

**怎么解约**:训练场 → 教练卡片 → "解约"按钮 → 确认。

**效果**:
- 教练立即**失效**(`isActive = false`)
- 之前分到这个教练的球员**回到未分配池**
- **不会再发周薪**
- 可能有**终止费**(按周薪补偿)

> 解约后想换人:**再签一个就行**(花新签约费)。"升级"教练其实就是这个流程。

---

## "升级"教练 = 解约 + 重新签

**没有"原地升级"**的机制。所谓的"升级"教练在系统里就是:
1. 解约现有教练(可能付终止费)
2. 重新签一个更高等级的(付新签约费)
3. 老的玩家分配丢了,**重新拖一遍**

> 短期"省钱"建议:**别每赛季都换**。Lv.3 中等教练能撑 2-3 赛季,只在球队冲冠时才上 Lv.4 / Lv.5。

---

## 专项教练怎么用(给球员)

每个专项教练**最多带 3 个球员**。详细机制见 [第 7 章](07-training.md),这里只列**教练侧**的事实:

- 教练可以**选 1 个"主训技能"**(技术上 / 心理上 / 定位球上 / 门将技能里挑)
- 每周结算时,带的学生按主训技能 → 改到顶 → 随机顺序练
- **教练的等级越高,带的球员拿到越多周点数**

---

## 队医(单独管理)

**队医不进训练场**,在"医疗室"页管。

**作用**:**加速伤病恢复**。等级越高,恢复越快。

| 队医等级 | 恢复加成 |
|---|---|
| Lv.1 | 1.1 倍 |
| Lv.2 | 1.2 倍 |
| Lv.3 | 1.3 倍 |
| Lv.4 | 1.4 倍 |
| Lv.5 | 1.5 倍 |

> 没签队医也能用,但**按基础速率恢复**(1.0 倍,更慢)。

---

## 合同与续约

每个教练都有**合同**:
- **到期日**(默认 16 周)
- **是否自动续约**(默认 true)
- 续约**不另收费**,只是再延 16 周
- **关掉自动续约** → 到期日 coach **自动失效**(没新合同)

**赛季结束时**:
- 自动续约 → 续 16 周,继续生效
- 不续约 → 失效,你下赛季没这个教练

**手动提前结束**:**解约**即可(立即失效 + 可能终止费)

---

## 怎么操作(总览)

1. **看现有教练** → 训练场看教练卡片(等级、岗位、带的球员)
2. **解约旧的**(如果要换)
3. **签新的** → 选岗位 → 选等级 → 选主训技能 → 确认付费
4. **给专项教练分配球员**(拖拽,每教练最多 3 人)
5. **每个教练设主训技能**(专项教练的"训练技能"下拉)
6. **队医单独管** → 医疗室 → 签 / 续约 / 解约
7. **等周四结算**

## 5 档价格(参考)

| 等级 | 周薪 | 签约费(16 周周薪) |
|---|---|---|
| Lv.1 | 500 | 8,000 |
| Lv.2 | 2,000 | 32,000 |
| Lv.3 | 8,000 | 128,000 |
| Lv.4 | 32,000 | 512,000 |
| Lv.5 | 128,000 | 2,048,000 |

**实战参考**:
- **前期**(刚接手球队):**别签**任何教练,等几周攒钱
- **早期主力成型**:**Lv.1 主教练 + Lv.1 体能教练**(加起来 1 千/周),够用
- **中游**:**Lv.2-3 专项**(总周薪 1-2 万)+ Lv.1 主教练
- **冲冠**:**Lv.4-5 主力**(单教练 13 万/周)—— 一个 Lv.5 = 200 多万现金签约,**慎签**

> 工资每周自动扣,**签约前看 [第 9 章:财政](09-finance.md)**。

## 常见错误

❌ **"我已经有教练了想升级"**:没有原地升级——**先解约再签**
❌ **"想签第三个专项教练"**:**最多 2 个专项**,要解约一个
❌ **"签完教练没看到"**:可能**扣了款但 isActive 没生效**,刷新训练场
❌ **"解约了没退钱"**:**不退还签约费**,只停发周薪
❌ **"合同到期教练没了"**:没开自动续约 → 到期自动失效。**赛季末记得开续约**
❌ **"队医没了"**:同上
❌ **"主训技能改了球员还在练别的"**:可能是**该技能已到潜力顶**,系统切到随机模式(见 [第 7 章](07-training.md))
❌ **"队医 Lv.5 太贵"**:**视伤病压力而定**。伤病多 → 买;伤病少 → Lv.1-2 够

## 跟其他概念的关系

| 概念 | 关系 |
|---|---|
| **训练**(第 7 章) | 教练是训练系统的核心,等级越高训练加成越大 |
| **伤病**(第 4 章) | 队医加速恢复,不直接影响场上表现 |
| **财政**(第 9 章) | 签约费 + 周薪都是开支,签之前看预算 |
| **阵容**(第 5 章) | 教练只管训练,**不管排阵容** |
