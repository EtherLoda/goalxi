# 阵容:基本认识

每场比赛前,你需要给球队**排一个阵容**。阵容决定:谁先发、谁替补、用什么阵型、按什么思路踢、比赛中什么时候换人。

一套完整的阵容包含五块内容:

- **首发** — 9-11 名场上球员(必须 1 个 GK,无重复)
- **替补** — 6 个替补位置(各放一名替补)
- **战术风格** — 节奏、球场宽度、防线高度,各 3 档
- **战术变化** — 比赛中触发的换人 / 移位安排(可选)
- **阵型显示** — **自动根据首发位置算出来**(不是手动选),常见的有 4-4-2、4-3-3、4-2-3-1 等

> 这一章讲**怎么排**。位置和头牌技能见 [第 3 章](03-positions.md),比赛里这些属性怎么作用见 [第 6 章](06-match-basics.md)。

---

## 首发

**首发 = 9-11 名场上球员**,每个对应一个具体位置。

**硬性规则**:
- **必须有 1 个 GK** 在 GK 位置(其他球员占不了 GK 位置,门将也不能去别处)
- **9-11 人**:少于 9 / 多于 11 都提交不了
- **不重复**:同一个球员不能同时占两个位置
- **都属于你的队**:替补席和青年队的球员不算

**位置分布**:由**你实际填的球员**决定(填什么位置就是什么位置)。系统自动按位置统计阵型。

> 头牌技能对不对位置,见 [第 3 章](03-positions.md)。**GK 的 9 项技能 + 场上球员的 10 项技能,每项都影响在这位置上的表现**。

---

## 替补

**替补席有 6 个位置**,每个位置只能放 1 个替补:

| 位置 | 覆盖范围 |
|---|---|
| 替补门将 | 任何门将 |
| 替补中卫 | 中卫家族(中后卫 / 左中卫 / 右中卫) |
| 替补边卫 | 边后卫 / 翼卫(覆盖左 / 右) |
| 替补边路 | 边锋(覆盖左 / 右) |
| 替补中场 | 中前卫 / 防守中场 / 前腰 |
| 替补前锋 | 中锋(覆盖左中 / 中 / 右中) |

> 替补席**不强制填满**。但填得越多,比赛中可换的余地越大。

**填替补也要遵守规则**:
- 替补 GK 只能放门将
- 其他替补可以跨位置(同一名中卫能放"替补中卫"也能放"替补边卫",只要适合)

## 阵型显示(自动)

**阵型不是选的**,**编辑器顶部会自动显示一个阵型代码**(如 4-4-2、4-3-3、3-5-2)。

**怎么算**:根据首发 11 人**实际填的位置**自动统计:
- **后防线人数** = LB / CBL / CB / CBR / RB / LWB / RWB 里填了人的数量
- **中场人数** = DMFL / DMF / DMFR / CML / CM / CMR / CAML / CAM / CAMR / LM / RM 里填了人的数量
- **前锋人数** = LW / RW / CFL / CF / CFR 里填了人的数量
- 显示成 `后防-中场-前锋` 的格式(门将 GK 不算入)

**实战含义**:你**只管填位置,阵型代码自动跟着变**。同一组球员,改一个位置就可能从 4-3-3 变成 4-2-3-1。

**常见阵型参考**:
- 4-4-2:经典均衡,2 前锋
- 4-3-3:边锋 + 单中锋
- 4-2-3-1:双后腰 + 前腰
- 3-5-2:三中卫 + 翼卫
- 5-4-1:五后卫密集防守

> 阵型代码**只是个标签**,让你知道当前阵容是几后卫 / 几中场 / 几前锋。具体效果看球员、头牌和战术风格。

## 战术风格(3 个维度)

每套阵容可设 3 个维度,**默认都是均衡**:

| 维度 | 档位 | 含义 |
|---|---|---|
| **节奏** | 慢 / 均衡 / 快 | 比赛推进速度(传球、跑动) |
| **球场宽度** | 窄 / 均衡 / 宽 | 利用球场横向空间(边路 vs 中路) |
| **防线高度** | 低 / 中 / 高 | 后卫线在球场上的位置(影响越位 / 反击) |

**怎么选**:
- **快节奏 + 宽 + 防线高** → 激进高压,适合强队碾压弱队
- **慢节奏 + 窄 + 防线低** → 防守反击,适合弱队对强队
- **均衡 / 均衡 / 中** → 通用,没想法就用这个

> 这三个维度**作用在整支球队的场上行为**上。具体效果详见 [第 15 章:比赛:战术](15-tactics.md)。

## 战术变化(比赛中触发)

**战术变化 = 你提前安排好的、比赛中某个时刻触发的操作**。两种类型:

### 换人(替补上 / 主力下)

- **指定时间**:在比赛的第几分钟(1-90)
- **谁下**:**首发**或**之前的替补**(已经在场上的)
- **谁上**:**替补**或**未上场的首发**
- **触发条件**:在指定时间 + 满足条件下才生效(下文 6 种)

### 移位(让某个球员换位置)

- **指定时间**:1-90 分钟
- **谁移**:**场上**某个球员
- **移到哪个位置**:**空着的位置**(同家族内移动)
- **触发条件**:6 种之一

> 移位是**同家族内换位**(例如中场球员从中前卫移到防守中场),**不是跨家族**。门将移不了位。

### 6 个触发条件

| 条件 | 含义 |
|---|---|
| **始终** | 不管比分,到了时间就触发 |
| **领先时** | 只在领先时触发 |
| **落后时** | 只在落后时触发 |
| **平局时** | 只在平局时触发 |
| **未领先时** | 落后或平局时触发(等于"领先时"的反面) |
| **未落后时** | 领先或平局时触发(等于"落后时"的反面) |

**实战常用**:
- **领先后稳守**:第 70 分钟 / 始终 / 换一名中场 → 上防守型中场
- **落后搏一搏**:第 60 分钟 / 落后时 / 上前锋 → 换下后卫
- **半场调整**:第 45 分钟 / 始终 / 边锋移位到前腰(变阵)

> 触发的换人 / 移位**也算一次战术调整**,会有对应事件记录(见 [第 6 章](06-match-basics.md))。

## 战术预设(保存反复用)

你可能为不同对手准备几套战术(主场 / 客场 / 强敌 / 弱旅)。GoalXI 允许**把整套战术保存为预设**,下次直接套用。

**预设包含**:
- 阵型 + 首发 + 替补
- 战术风格(节奏 / 球场宽度 / 防线高度)
- 战术变化(换人 / 移位列表)

**预设规则**:
- 队内**多个预设**,但只能有 **1 个默认预设**
- 预设**名称唯一**(同一队不能重名)
- **默认预设不能删**(先把另一个设为默认)
- 提交战术时,可以**指定一个预设 ID**,系统把预设内容填入

**典型用法**:
- "主场强攻" / "客场稳守" / "对强敌摆大巴"
- 比赛前 5 分钟 → 应用预设 → 提交

## 提交与锁定

**比赛状态机**:

```
已安排 → 战术已锁定 → 进行中 → 已结束
```

- **已安排**:可以提交 / 修改战术
- **战术已锁定**:**不能再改**,比赛即将开始
- **进行中**:比赛中,提交已关闭
- **已结束**:比赛完成

**什么时候锁**:
- **比赛前 30 分钟,UI 自动锁住编辑器**(此时 UI 还会显示倒计时)
- 比赛开球即锁
- 锁后只能看,不能改

> 锁定后**未提交战术 = 提交失败**。请在锁定前完成提交。

## 怎么操作(总览)

1. 进入比赛详情页 → 点击"布阵"
2. **拖球员到场上位置** → 首发 9-11 人(必须 1 GK)
3. **拖球员到替补席** → 替补 0-6 人
4. **看编辑器顶部的阵型代码** → 随位置自动变
5. **调战术风格** → 节奏 / 球场宽度 / 防线高度
6. **添加战术变化**(可选)→ 换人 / 移位 + 时间 + 条件
7. **保存为预设**(可选)→ 命名,可选"设为默认"
8. **提交战术** → 比赛前 30 分钟前完成

> 编辑器会**实时校验**:GK 位置不对、人数不够、球员不属于本队,都会在提交前弹错。

## 常见错误

❌ **GK 位置不安排 GK**:**门将只能去 GK**(场上 + 替补 GK 槽),占别的位置不算
❌ **首发 8 人 / 12 人**:**必须 9-11 人**,少了提交不过,多了塞不进
❌ **同一球员占两个位置**:**不重复**,谁先拖进去就归谁
❌ **用对手 / 其他队的球员**:**不认**,只认自己队的人
❌ **预设重名**:**同一队不能两个"主场 4-3-3"**,改名再存
❌ **删默认预设**:**不能**,先指定别的为默认
❌ **锁后还在改**:**比赛前 30 分钟就锁了**,要改就提前
❌ **不填替补**:**能提交**,但比赛中 0 个换人名额。强烈建议至少填 1-2 个
❌ **换人时间用 0 / 95**:**1-90 分钟**,1 以下或 91 以上都报错
❌ **移位给门将**:**门将不移位**,GK 位置不参与移位
❌ **移位跨家族**:**同家族内移位**(中前卫 → 防守中场 OK,中前卫 → 边锋不行)
