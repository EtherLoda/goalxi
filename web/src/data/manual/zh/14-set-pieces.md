# 比赛:定位球和特别事件

比赛中的"非套路"事件 — **角球、任意球、点球、红黄牌、受伤、乌龙、加时和点球大战** — 都会改写比分或场上人数。比赛已经按你的阵容和战术预设自动跑完,你不能赛中叫暂停选人,只能**赛前通过阵容、替补、特性搭配来间接影响**。

> **关于越位**:引擎里**已经铺好了基础设施**(事件类型、统计字段、解说模板、防线高度对应概率常量),但**目前**模拟逻辑还没接入 — 也就是说**场上不会真正吹越位**,FE 也看不到任何越位事件。详细见下文"越位"段。

这一章讲**这些事件在比赛里怎么发生、你能看到什么、它们怎么和球员的属性 / 特性挂钩**。比赛整体怎么走见 [第 6 章](06-match-basics.md),怎么排阵容见 [第 5 章](05-lineup-basics.md),战术怎么调见 [第 15 章](15-tactics.md)。

## 一、定位球(3 大类)

定位球 = 在固定位置重新开球,**不进** 90 分钟常规流动,**统一由系统处理**。场上 3 大类:

| 类型 | 触发 | 频率(每场双方合计) | 常见结果 |
|---|---|---|---|
| **角球** | 球被防守方碰出底线 | 高(8-12 次) | 大多数解围 / 顶高 / 扑救;直接破门**少** |
| **任意球**(直接) | 禁区前沿犯规,可以直接射门 | 少(不到 2 次) | 远射 / 人墙挡出 / 扑救;直接破门**少但有** |
| **任意球**(间接) | 禁区内任意球 / 战术犯规 | 中(几次) | 短传配合 / 远射;破门**比直接任意球多一点** |
| **点球** | 禁区内犯规被判极刑 | 极少(每场不到 1 次) | 罚进率高,关键判罚 |

### 角球

**怎么产生**:球被防守方(后卫 / 门将)碰出**自己**的底线,进攻方在**角旗区**重新开球。

**主罚谁踢**:系统**自动**按场上球员的 `freeKicks(任意球)` 技能排序选主罚人,**AM / CM 位置有加成**。你**不能**在阵容里指定"任意球 / 角球主罚人",阵容里没这个字段。

**进球率**:角球**本身**一般不进时间轴(频率太高),但如果进球会显示"进球 + 角球配合"。角球的进球率不高 — 大多数角球被解围、被门将出击没收、被顶偏。

**你能看到什么**:
- **解说**(实时文字):"{队} 获得 {左路/中路/右路} 角球,{主罚球员} 站在角旗区准备主罚"
- **时间轴**:角球本身**通常不**列在时间轴;但角球产生的进球会列
- **赛后报告**:角球数 = 你方角球数(统计页能看到)

### 任意球(直接 + 间接)

**怎么产生**:普通犯规(铲断、拉拽、推人)→ 裁判鸣哨 → 在犯规点给被犯规方一个**定位球**。

**两种**:
- **直接任意球** — 可以在犯规点**直接射门**(禁区前沿常见)
- **间接任意球** — 不能直接射门,必须先**短传给队友**,再由队友射门(禁区内任意球 / 战术犯规常见)

**主罚谁踢**:同样按 `freeKicks` 自动选,AM / CM 有加成。

**进球率**:
- **直接任意球** — 进球率低但**有威胁**,远射破门虽然不多但每场可能出现
- **间接任意球** — 进球率比直接任意球**稍高**(因为多一脚配合)

**你能看到什么**:
- **解说**:犯规 → 任意球(显示是"绝佳定位球机会"还是"普通定位球")
- **进球**:如果直接任意球进球,会显示在时间轴 + 解说模板(直接任意球破门的描述)
- **间接任意球进球**:走普通进球流程,跟常规进球描述接近

### 点球

**怎么产生**:**禁区内犯规** → 主裁判**手指点球点** → 在 12 码处单挑门将。

**主罚谁踢**:系统按场上球员的 `penalties(点球)` 技能自动选主罚,**AM / CM 位置有加成**。你不能在阵容里指定。

**进球率**:**高**(真实足球 70-80% 量级,游戏里接近),是场上**单次事件**得分概率最高的。

**老将为什么稳**(经验红利):
点球判罚**用专门的加成 — 只看 form + experience,不看体能**。意思是说:
- **满血 vs 体能见底** — 踢点球**没区别**(体能不影响点球)
- **老将(form 不好但 experience 很高)vs 新兵(form 极好但 experience 低)** — 老将**点球更稳**

详细见 [第 4 章](04-player-attributes.md) "老将点球红利"。

**你能看到什么**:
- **解说**:点球前会有一段紧张铺垫("全场的目光都集中在罚球点上")
- **时间轴**:点球会显示
- **罚失**:会单独显示"点球罚失",分两种结果 — **门将扑出** / **射偏**(擦立柱 / 击中门柱 / 打高)

**GK 端 — 扑救加成**:
GK 拿 `SAVING_MASTER(扑救大师)` 特性(GOLD 强度最高)→ 扑点球能力**叠加**(在原有扑救基础上额外加成)。这是 GK 端**唯一直接**影响点球结果的特性。

## 二、特别事件

### 越位

**怎么产生**:进攻球员在队友传球瞬间**比球更靠近对方底线**,且当时**身前只有门将** → 边裁举旗 → 判越位,进攻方**失去球权**。

**当前状态 — 模拟逻辑未接入**:

引擎里**已经铺好了越位的基础设施**,但**目前模拟逻辑还没接上**:
- 事件类型 `'offside'` 已经在 type union 声明
- 防线高度对应的越位概率常量已经定好(低 1% / 中 4% / 高 15%)
- 赛后统计字段 `offsides` 已经存在
- FE 越位解说模板已经备好(2 句)
- **但是引擎代码里没有任何 `events.push({ type: 'offside' })` 调用** — 模拟不会真的产出越位事件

**对玩家的实际影响**:
- **场上不会真吹越位** — 不管你防线多高,都不影响比赛
- **FE 看不到任何越位** — 时间轴没显示,赛后统计永远 0,解说也不弹
- **战术 trade-off 不存在** — 防线高度目前**只**影响**进攻压迫** vs **反击暴露**(见 [第 15 章](15-tactics.md)),**不影响越位**
- 等模拟逻辑接上后,上面这些都会自动生效 — 数据基础已经在那

> **如果未来接入了,会怎么表现**(链 [第 15 章](15-tactics.md)):
> - 防线越高 → 越位概率越高
> - 越位不进时间轴(频率高,跟犯规类似)
> - 赛后统计会显示越位次数
> - 解说偶尔会蹦一句"边裁举旗了,{队} 越位在先"
> 但**现在还没接**,玩家在游戏里看不到这些效果。

### 红黄牌

**黄牌(警告)**:
- **累积规则**:**同一球员本场第 2 张黄牌 = 红牌**(罚下)
- 进时间轴 + 解说("黄牌!裁判向 {球员} 出示了警告")
- 战术犯规 / 延误时间 / 异议裁判 → 容易吃黄

**红牌**:
- **直接红牌** — 严重犯规(暴力行为、恶意犯规、破坏明显进球机会),**极少见**
- **第二张黄牌** — 同一球员本场第 2 张黄 → 升级为红牌,**罚下**
- 两种情况在系统里**都记录为 `red_card` 事件**(解说可能说"第二张黄牌变红"但事件类型是红牌)

**罚下后怎么办**:
- 球员**立即离场**,**不**能替补上场(10 人应战)
- 不是所有比赛都会出红牌 — 大部分比赛是 11 vs 11
- 红牌事件**进时间轴**,有清晰图标

**频率**(参考):
- **黄牌**:每场双方合计几次
- **红牌**:大多数比赛**没有**;出红牌的比赛少,直接红牌**更少**

### 受伤

比赛里触发:铲断受伤 / 过度使用 → 系统判定**轻 / 中 / 重**三档。

- **轻伤(mild)**:还能踢,**能力下降**
- **中度(moderate)**:必须离场,**触发自动换人**(从替补选对应位置)
- **重度(severe)**:必须离场,**触发自动换人**

详细见 [第 4 章](04-player-attributes.md) "伤病状态" 段。受伤**不是** 100% 触发换人 — **取决于你阵容里有没有同位置替补**;没替补可用时,中度 / 重度伤病的球员**会被判送下场(send-off)**,走 10 人。

### 乌龙球

**怎么产生**:本方球员在防守中**把球弄进自家球门**(解围失误、门将扑救脱手等)。

**进时间轴**:会,**显示"乌龙球"**。

**算谁的进球**:算**对方**进球,跟正常进球一样更新比分。

**怎么看**:球员详情页事件历史会记一条 `goal`(但 tag 是 `own_goal`);**不**影响该球员的"进球数"统计(乌龙球不算个人进球)。

### 弃权

**怎么产生**:一方**无法出场**(如球队解散、严重违规),系统判对方 3-0 胜。

详细见 [第 6 章](06-match-basics.md) "弃权" 段。极少见。

## 三、加时 + 点球大战

### 什么时候打

**不是每场都打**:
- **联赛** — 90 分钟战平,直接结束(各拿 1 分)
- **杯赛 / 季后赛** — 90 分钟战平,**进加时**
- **友谊赛 / 锦标赛** — 按赛事规则

### 加时流程

```
90 分钟战平
  ↓
加时上半场(15 分钟,91'-105')
  ↓
加时上下半场之间休息(5 分钟)
  ↓
加时下半场(15 分钟,106'-120')
  ↓
仍然战平 → 点球大战
```

加时期间的**规则跟常规时间一样**(角球、任意球、点球、红黄牌全都适用),只是时间更短。

### 点球大战

**怎么踢**:
- 双方**各踢 5 轮**,轮换着踢(主队先)
- 5 轮结束**比分仍然平** → 突然死亡(各 1 轮,先领先者胜)
- **没人数限制** — 突然死亡可以一直踢

**主罚顺序**:
- 系统**按球员列表顺序**选未被罚下的人踢(主队从首发 11 人按位置顺序开始,客队同样)
- **不是**按"谁点球最强" — 跟常规点球(第 1 节)的"按 penalties 技能选主罚"不同

**老将还是稳吗**:
**是**。点球大战跟常规点球**用同一套加成** — form + experience,所以老将点球大战**也**比新兵稳。

**统计怎么算**(关键!):
- 点球大战的进球**算最终比赛结果**(影响晋级 / 联赛积分)
- **但** — **不**进球员个人进球统计(不进球员详情页事件历史的 `goal` 列表),**只**作为比赛胜负标记
- 这跟常规点球进个人统计**不同**

## 四、特别事件跟球员的关系

### 你能间接影响的部分

定位球 / 特别事件**赛中不能手动操作**,但**赛前**能通过以下间接影响:

| 赛前决策 | 影响哪些事件 |
|---|---|
| **首发 11 人 + 替补 6 人** | 主罚点球 / 任意球的候选池(系统从中选) |
| **球员的 `freeKicks` / `penalties` 技能** | 决定主罚排序 — 技能高的优先 |
| **球员位置(AM / CM vs 其他)** | 主罚排序**有加成**(AM / CM 加成最大) |
| **球员的 `specialty` 特性** | 影响对应事件(见下表) |
| **战术 — 防线高度** | 进攻压迫 / 反击暴露(越位逻辑未接入,目前不影响越位) |
| **替补配置** | 中度 / 重度受伤时**能否自动换人**(有替补 = 换人,没替补 = 送下场) |
| **GK 的 `SAVING_MASTER` 特性** | 扑点球 / 关键扑救加成 |

### 哪些特性跟定位球 / 特别事件挂钩

虽然 12 种特性主要是"决策 / 进攻 / 防守"加成,但有几个**直接**影响定位球 / 特别事件:

| 特性 | 触发的特别事件 |
|---|---|
| `SAVING_MASTER`(扑救大师) | **GK 扑点球 + 关键扑救**(点球大战也生效) |
| `AERIAL_THREAT`(空霸) | **角球 / 任意球的争顶** |
| `POACHER`(机会主义) | **定位球二次进攻的抢点 / 捡漏** |
| `WALL`(铁墙) | **防守端封堵对方定位球进攻** |
| `COMPOSED`(冷静) | **点球主罚 + 单刀处理** |

> 12 种特性和 3 档强度的完整说明见 [第 4 章](04-player-attributes.md) "specialties" 段和 `specialties-meaning` 条目。

## 五、怎么准备定位球 / 特别事件

定位球 / 特别事件**赛前没有专门的设置页**。你**能做的**就是间接准备:

1. **阵容选人** — 找有 `freeKicks` / `penalties` 高分的球员(尤其是 AM / CM),自动成为主罚候选
2. **GK 选人** — 找有 `SAVING_MASTER` 的 GK(GOLD > SILVER > BRONZE),点球防守加成
3. **特性搭配** — 阵地战多 → 找 `POACHER` / `AERIAL_THREAT` / `COMPOSED`;反击多 → 找 `SPEEDSTER`
4. **替补配置** — 同位置必须有替补,否则中度 / 重度伤病会**直接送下场**(10 人)
5. **战术 — 防线高度** — 影响**进攻压迫**和**反击暴露**的 trade-off(目前不影响越位,见上文)

## 六、常见错误

❌ **"为什么角球不进时间轴"**:角球频率高(每场 8-12 次),**只显示进球**,不显示每次开球
❌ **"为什么看不到越位"**:**目前引擎还没接入越位模拟**,场上不吹越位,FE 也看不到任何越位事件(基础设施已经铺好,等模拟接上就生效)
❌ **"红牌能不能换人"**:**不能**。红牌罚下后**只能 10 人应战**,系统**不**自动补人
❌ **"第二张黄牌是黄牌还是红牌"**:**显示为红牌**(事件类型 `red_card`),解说会提"第二张黄牌"
❌ **"点球大战进球算不算个人数据"**:**不算**。算比赛结果,**不**进球员进球统计
❌ **"点球老将是不是更稳"**:**是**。点球只用 form + experience,**不看体能**,所以经验加成照常生效
❌ **"能不能选主罚"**:**不能**。主罚**自动**按 penalties / freeKicks 技能 + 位置加成选
❌ **"GK 没扑出点球是不是 GK 弱"**:不一定 — 点球**整体进球率高**,扑不出是常态;要看**多次**扑救率,不是单次
❌ **"高线战术 = 越位多 = 战术失败"**:**目前高线不会触发更多越位**(越位模拟未接入),高线真正的 cost 是**被反击打穿**
❌ **"轻伤球员为什么表现差"**:轻伤 = 可上场但**能力下降**,**不**是 bug

## 七、跟其他概念的关系

| 概念 | 关系 |
|---|---|
| **比赛基本信息**(第 6 章) | 比赛直播的事件流、时间轴、解说都包含定位球 / 特别事件 |
| **阵容**(第 5 章) | 首发 11 人 + 替补 6 人 = 主罚候选池 + 自动换人候选 |
| **球员属性**(第 4 章) | form / experience / 比赛中当前体能 → 决定定位球表现(点球只看 form + exp) |
| **specialties**(第 4 章) | SAVING_MASTER / AERIAL_THREAT / POACHER 等直接影响定位球 / 特别事件 |
| **战术**(第 15 章) | 防线高度影响**进攻压迫 / 反击暴露** trade-off(越位逻辑未接入,目前不影响越位) |
| **球员事件历史**(`player-event-types` 条目) | 球员详情页的 `goal` / `INJURY` / `HAT_TRICK` 等事件不包含定位球类型,**只**记录个人成就 |
