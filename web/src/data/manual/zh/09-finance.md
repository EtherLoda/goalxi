# 财政

球队赚钱、花钱,要从钱包角度看。这一章讲**钱从哪来、钱往哪花、怎么避免破产**。

> 球场建设/扩容见 [第 11 章:球场](11-stadium.md)。买 / 卖球员见 [第 18 章:转会](18-transfer.md)。教练工资 / 签约费见 [第 8 章:教练](08-staff.md)。

---

## 货币

- 游戏内**唯一货币**:**Goalxi Coin**
- 没有金币 / 钻石 / 欧元等别的货币
- 起始资金:**10 万**

## 每周结算(自动)

**每周日**(周一显示)系统自动跑一次结算,改你的钱包:

### 收入(每周)

| 项 | 来源 | 备注 |
|---|---|---|
| **赞助商** | 联赛按周发 | L1 = 10 万/周基础,L5 = 3 万/周(随级别降) |
| **门票收入** | 主场每场比赛后 | 现场观众 × 单价 × 联赛系数 |
| **其他收入** | 杂项 | 不常出现 |

**赞助商**会按球迷数加成(基础值 × 2 × √(球迷/1万))。**L1 + 球迷多 = 钱多**。

**门票**只在**有主场比赛**时入账。L1 的门票系数 2.0(最贵),L4+ 1.0(最便宜)。

### 支出(每周)

| 项 | 谁付 | 备注 |
|---|---|---|
| **球员工资** | 11 个主力(或更多) | 按每个球员的 currentWage 总和 |
| **教练工资** | 主教练 + 体能教练 + 专项教练 | **主教练 ×2**;按等级 2k-25k/周 |
| **青训运营** | 全队 | 固定 2.5 万/周 |
| **球场维护** | 拥有已建球场的队 | 座位数 × 2/周 |

**球员工资**是最大的固定支出。技能高的球员工资贵(高技能 = 高工资)。

**教练工资**:5 档等级,周薪 2k-25k。**主教练 ×2** 是按等级再翻倍(L1 主教练 = 4k,L5 主教练 = 50k)。

**青训** 2.5 万/周固定扣,即使你**不签青年球员**也照扣(系统后台在跑)。

**球场维护**只对**已建球场**的球队算。**没球场 = 0**。

## 不规则收入 / 支出

只在**发生**时入账:

| 事件 | 项 | 备注 |
|---|---|---|
| 赛季结束排名 | **奖金** | L1 冠军 600 万,第 8 名 100 万;L5 冠军 120 万,第 8 名 20 万 |
| 卖球员 | **转会收入** | 成交价 |
| 买球员 | **转会支出** | 成交价 |
| 签教练 | **签约费** | 周薪 × 16 |
| 解约教练 | 可能扣**终止费** | 看你合同剩余 |
| 球场建造 / 升级 | **建设费** | 大额,见 ch 11 |
| 弃权 | 0 | 对手 3-0 拿走 3 分 |

## 排名奖金(5 档联赛)

**赛季末**(第 16 周后)按你的联赛名次拿钱:

| 联赛 | 第 1 名 | 第 2 名 | 第 3-4 名 | 第 5-8 名 |
|---|---|---|---|---|
| **L1** | 6,000,000 | 3,600,000 | 2,000,000 | 1,000,000 |
| **L2** | 4,000,000 | 2,400,000 | 1,300,000 | 640,000 |
| **L3** | 2,400,000 | 1,440,000 | 800,000 | 400,000 |
| **L4** | 1,600,000 | 960,000 | 520,000 | 260,000 |
| **L5+** | 1,200,000 | 720,000 | 400,000 | 200,000 |

> 冠军奖金 ≈ 一个队 5-10 周的赞助商 + 门票收入,看你什么联赛。**降级区不奖**(第 9 名及之后无奖金,但还要继续踢)。

## 怎么查(财务中心)

进"球队" → "财务"页:

- **当前预算**:实时显示(随交易更新)
- **实时同步**:本周 / 上周收支分项
- **收入分项**:赞助商、门票、转会、其他
- **支出分项**:球员工资、教练工资、青训、转会、维护
- **财务趋势**:近 8 周收入 / 支出柱图
- **现金流分析**:周均 / 年度预测
- **按赛季+周次筛选**:查任意历史周
- **查看详细记录**:每笔交易带描述

## 实战参考(收支量级)

**L1 中游队**(中等水平的球员 + 中档教练):

| 项 | 周金额 |
|---|---|
| 赞助商 | ~100k-200k(看球迷) |
| 门票(主场比赛) | ~50k-150k(看主场上座) |
| 球员工资 | 30k-80k(看阵容) |
| 教练工资 | 10k-30k(看等级) |
| 青训 | 25k |
| 球场维护 | 10k-30k(看容量) |
| **净周收入(有主场比赛)** | ~80k-180k |
| **净周收入(客场比赛)** | ~10k-60k(没门票) |

**一个赛季 16 周,大致估算**:
- 中游 L1 队:**净收入 100-200 万 / 赛季**
- 算上排名奖金(假设第 4-8 名):+ 100-200 万
- **赛季总收入 ~200-400 万**

> 跟 L1 冠军 600 万比,**冠军一季能抵亚军两三季**。中游靠稳,冠军靠拼。

## 5 大误区

❌ **"起始 10 万很多"**:看着多,**签个 S 级教练就 -200 万**(签约费),买一个 18 技能球员 -50-100 万,几笔就空了
❌ **"排名奖金好赚"**:**第 8 名才有 100 万**。第 9 名之后 0。中下游球队靠**赞助商 + 门票**过日子,不是靠奖金
❌ **"客场没收入"**:客场是没钱进账,但**工资照发、青训照扣、教练照扣**——这周就是纯支出周
❌ **"教练工资只算签的人"**:不,**主教练 + 体能教练 + 全部专项教练** + **全队球员**都算
❌ **"青训不签人就不扣"**:照扣,2.5 万/周,跟青年运营无关

## 怎么避免破产

- **看赛季总收入 vs 总支出**,留 **2-3 赛季缓冲** 应急
- **主力不要全 18 技能** — 工资按技能算,**16 技能主力便宜得多**
- **签约前必看钱包**:5 档教练签约费 8k → 200 万,一个 S 级 ≈ 一个中游队一赛季奖金
- **球场别乱扩**:容量 ↑ → 门票 ↑ → 维护费 ↑(**不扩建 = 0 维护**)
- **赛季末拿到排名奖金再升级阵容**

## 跟其他概念的关系

| 概念 | 关系 |
|---|---|
| **教练**(第 8 章) | 工资 + 签约费 + 终止费 三大支出 |
| **球场**(第 11 章) | 建造 / 扩容 一次大额;维护每周扣 |
| **比赛**(第 6 章) | 门票 = 现场观众 × 单价 × 联赛系数 |
| **球迷**(第 10 章) | 球迷数 ↑ → 赞助商加成 ↑(公式) |
| **转会**(第 18 章) | 卖人入账、买人扣款 |
| **排名奖金** | 跟名次 + 联赛相关,赛季末 1 次 |
