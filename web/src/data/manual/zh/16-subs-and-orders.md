# 比赛:替补和球队指示

第 5 章讲过**怎么排**(阵容 + 替补席 + 怎么加一条赛中调整),这一章讲**赛中调整的规则细节**:上限、条件怎么判、什么时候会被忽略、伤病怎么自动处理,以及**实战怎么用**。

一句话:**所有赛中调整都是赛前就排好的,比赛开始后你不能再动**。第 15 章管的是"球队整体风格",这一章管的是"什么时候、换谁"。

---

## 0. 快速参考

| 项目 | 规则 |
|---|---|
| 替补席 | **6 个位置**(可选填空) |
| **主动换人上限** | **每场最多 3 人** |
| **伤病换人** | **由队医自动处理,不占上面这 3 个名额** |
| **移位** | **不限次数** |
| 一条调整 = | 分钟 + 条件 +(换人:谁下谁上 / 移位:谁移到哪) |
| 触发条件 | 6 种(始终 / 领先 / 落后 / 平局 / 未领先 / 未落后) |
| UI 锁定 | 开赛前**约 30 分钟**(编辑器变只读) |
| 后端硬锁 | 开赛前**约 10 分钟**(服务器拒收) |

---

## 一、替补席(6 个位置)

替补席**不强制填满**(0-6 人),但填得越多,比赛中可换的余地越大。

| 替补位 | 能放谁 |
|---|---|
| 替补门将 | 任何门将 |
| 替补中卫 | 中卫家族(中后卫 / 左中卫 / 右中卫) |
| 替补边卫 | 边后卫 / 翼卫(覆盖左 / 右) |
| 替补边路 | 边锋(覆盖左 / 右) |
| 替补中场 | 中前卫 / 防守中场 / 前腰 |
| 替补前锋 | 中锋(覆盖左中 / 中 / 右中) |

> **替补门将位只能放门将**,其他替补位不能放门将。放错会被校验拦下。

**只填 1 个替补会怎样**:能提交,但整场你最多只有这 1 个人可换,而且如果他不在伤员的位置家族里,伤病也换不了(见第五节)。

---

## 二、两类赛中调整

### 换人(sub)

一名**场上球员**下,一名**替补席球员**上。

| 字段 | 说明 |
|---|---|
| **分钟** | 第几分钟触发(1-90) |
| **谁下** | 场上任意球员(不能是已被罚下的) |
| **谁上** | 替补席上的球员 |
| **条件** | 6 种之一(默认"始终") |

### 移位(move)

让一名**场上球员**换到一个**空着的位置**。

| 字段 | 说明 |
|---|---|
| **分钟** | 第几分钟触发(1-90) |
| **谁移** | 场上某个球员 |
| **移到哪** | 目标位置必须**当前空着** |
| **条件** | 6 种之一 |

> 移位**不消耗换人名额**,想排几条排几条。移位是**位置调整**,不是换人 —— 场上还是同样 11 个人。

**两类调整的对比**:

| | 换人 | 移位 |
|---|---|---|
| 消耗名额 | ✅ 占 1 个主动换人名额 | ❌ 不占 |
| 人数变化 | 上 1 人下 1 人 | 不变 |
| 触发后 | 上场球员**继承下场球员的位置** | 移到指定位置 |

---

## 三、主动换人上限:每场 3 人

**这是本章最重要的一条规则。**

一支球队在一场比赛里,**主动换人最多 3 人**。这是硬上限,任何情况下都不能超过。

### 什么算、什么不算

| 情况 | 算不算名额 |
|---|---|
| 你赛前排的**换人** | ✅ **算**(每排一条占 1 个) |
| **移位** | ❌ 不算 |
| **伤病换人**(队医自动做的) | ❌ **不算** |
| 球员被罚下 | ❌ 不算(也不能补人) |

### 编辑器会直接拦住你

超过 3 条之后,"换人"按钮不会再加新行了,并且会弹一句提示。**服务端也会拒收**超过 3 条的提交 —— 所以不要指望靠改请求绕过。

### 伤病换人不占名额 → 实际换人次数可能超过 3

上限管的是**你的决定**,不是**场上的意外**。一场伤病多的比赛,你可能 3 次主动换人用完 + 又发生 2 次伤病换人,**一共换了 5 个人**。这是设计如此,不是 bug。

### 常见误区

❌ **"换人想换几次换几次"**:**主动换人每场最多 3 人**,这是硬规则。

❌ **"我要留名额给伤病"**:**不用**。伤病换人不占名额,所以**该排满 3 条就排满 3 条**。留着的名额不会结转,也不会变成伤病用的余地。

❌ **"移位也占名额"**:**不占**。移位不限次数。

## 四、6 个触发条件

每条调整都可以设一个**触发条件**。条件在**那一分钟开始时**判断一次:满足 → 执行;不满足 → **这条直接作废**(不会等到以后再说)。

| 条件 | 含义 |
|---|---|
| **始终** | 不管比分,到了时间就触发(**默认**) |
| **领先时** | 只在领先时触发 |
| **落后时** | 只在落后时触发 |
| **平局时** | 只在平局时触发 |
| **未领先时** | 落后或平局时触发(= "领先时"的反面) |
| **未落后时** | 领先或平局时触发(= "落后时"的反面) |

**怎么选**:

| 你想干的事 | 用哪个条件 |
|---|---|
| 到点就换,不管比分 | 始终 |
| 领先后稳守(上防守型中场) | 领先时(或"未落后时",更早一点上) |
| 落后搏命(上前锋) | 落后时(或"未领先时",更早一点上) |
| 只有僵局才调整 | 平局时 |

> **默认是"始终"**。不设条件就是到点必触发。

---

## 五、伤病换人(强制,不占名额)

比赛中球员会受伤,严重伤病**必须下场**。这类换人**不需要你安排**:

1. 队医判断伤情。**轻伤** → 球员可以继续踢;**重伤** → **必须下场**。
2. 引擎自动在替补席上找**同一位置家族**的替补,找到就换上。
3. **找不到替补** → 这名球员直接下场,**球队少打一人**(赛后事件里会看到,原因标注为"伤病,无人可换")。
4. 如果这一条是伤病换人,**不消耗你的 3 个主动换人名额**。

**所以替补席别只填一两个。** 伤病发生在哪个位置家族是随机的,替补席越全,越不容易少打一人。

> **伤病换人不看你的战术安排** —— 它是引擎在比赛中即时决定的,你排的换人顺序不会影响它。

## 六、提交与锁定

| 状态 | 会发生什么 |
|---|---|
| 开赛前 30 分钟以外 | 随便改(阵容 / 替补 / 调整 / 战术) |
| 开赛前约 **30 分钟** | **UI 锁**:编辑器变只读,倒计时 |
| 开赛前约 **10 分钟** | **后端硬锁**:服务器拒绝新提交 |
| 比赛进行中 | **锁死**,不能改任何东西 |
| 比赛结束 | 已成历史,不能改 |

> **赛中调整也是战术提交的一部分**,同样受这两个锁定时间限制 —— 不是"开赛后还能临场改"。

---

## 七、实战组合(5 个常见套路)

### 1. 领先稳守

- 第 60-70 分钟 / **领先时** / 换下一名进攻球员,换上一名防守型中场或中卫
- 配合第 15 章的"窄 + 低防线",或第 28 章的"防守反击"

### 2. 落后搏命

- 第 55-65 分钟 / **落后时** / 换下一名后卫,换上前锋
- 配合"宽 + 高防线",或第 28 章的"高位逼抢"

### 3. 体能见底

- 第 65-75 分钟 / **始终** / 换下体能最差的球员(通常是被压着打的那一侧)
- 这类换人不看比分,用"始终"最省事

### 4. 伤病预案

- 替补席**填满 6 个**(尤其门将 + 中卫 + 中场)
- 不排换人也能靠队医兜底;排了主动换人也不影响伤病换人

### 5. 少打一人时

- 被罚下后**不能补人**,只能靠排好的移位把阵型往回收
- 例如:红牌后第 70 分钟 / **始终** / 把边锋移回边后卫位置

---

## 八、目前不能做

- **不能赛中手动操作** —— 没有"暂停 → 点换人"这种交互。所有调整赛前排好。
- **不能改阵型** —— 移位能挪人,但不能把 4-3-3 改成 5-3-2。
- **红牌后不会自动重排** —— 少打一人时阵型不变,需要自己用移位弥补。
- **没有换人窗口概念** —— 只看**总次数**(3 人),不看分几个时间点换。
- **不能换下已被罚下的球员** —— 他已经不在场上了。
- **被换下的球员不能再上场** —— 一次换人 = 一名场上球员下、一名替补上。

---

## 九、常见误区

❌ **"换人不限次数"**:**主动换人每场最多 3 人**。

❌ **"伤病换人也要占名额"**:**不占**。你的 3 个名额只算自己排的换人。

❌ **"排了就一定执行"**:条件不满足 → **直接作废**;被换下的人已经不在场上 → **这条不生效**;移位目标位置已被占 → **不生效**。

❌ **"锁了还能改"**:UI 锁了就别再试,后端约 10 分钟前就拒收。

❌ **"红牌后能补人"**:**不能**。少打一人,只能靠移位调整。

❌ **"替补不用填满"**:能提交,但**替补越少,伤病时越可能少打一人**。
