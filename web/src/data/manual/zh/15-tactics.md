# 比赛:战术

战术风格 = 你在**每场比赛开始前**设定的 3 个维度(节奏 / 球场宽度 / 防线高度),各 3 档,作用在**整支球队**的场上行为上。比赛已经开打,战术就锁死了,你不能赛中改。

第 5 章讲过**怎么提交战术**(UI / 预设 / 锁定),这一章讲**3 个维度各自怎么影响比赛**,以及**怎么根据对手和球员搭配**。

---

## 3 个维度(快速参考)

| 维度 | 档位 | 关键作用 | 跟球员的关系 |
|---|---|---|---|
| **节奏**(tempo) | 慢 / 均衡 / 快 | 决定进攻节奏(快 = 反击多,慢 = 阵地多)和**丢球后的反应** | 头牌速度 / 传球 决定能不能玩快 |
| **球场宽度**(pitchWidth) | 窄 / 均衡 / 宽 | 决定走**边路**还是**中路** | W 边锋 / LB 翼卫 在宽阵更舒服;AM 前腰 / CM 中场 在窄阵更舒服 |
| **防线高度**(defensiveLine) | 低 / 中 / 高 | 决定**进攻压迫**和**反击暴露**(越位逻辑未接入,目前不影响越位) | 高速 CB 在高线更舒服;慢速 CB 在低线更稳 |

> 3 维度**默认都是均衡**(节奏均衡 / 球场均衡 / 防线中)。没想法就用默认。

---

## 一、节奏(tempo)

**节奏 = 球队整体推进速度**,分 3 档:

### 慢节奏

- **进攻方式**:短传配合为主,**少走反击**,控球稳
- **比赛特点**:**射门次数少但质量稳定**,丢球反应**慢**(丢球后反应稍慢,容易给对手二点机会)
- **适合**:
  - 球员**个人能力弱**于对手 → 控球减少失误
  - **中后场为主**(5-3-2 / 5-4-1 之类)
  - **领先后稳守**(配合战术变化,见 [第 16 章](16-subs-and-orders.md))

### 均衡节奏

- 短传 / 长传 / 直塞 / 过人 / 远射 比例**平均**
- **默认**,没想法就用这个

### 快节奏

- **进攻方式**:**直塞 + 过人**为主,多打反击,**直接冲击对方防线**
- **比赛特点**:**射门次数多**,丢球反应**快**(丢球后立刻反抢),但**容易失误**(传球精度下降)
- **适合**:
  - 球队有 **高速球员**(SPEEDSTER 边锋 / COMPOSED 前锋)
  - **前场三叉戟**阵容(4-3-3 / 4-2-3-1)
  - 追分时(配合战术变化换前锋)

### 怎么选

| 你的情况 | 推节奏 |
|---|---|
| **球员速度 / 传球高**,对手弱 | **快** — 碾压 |
| **球员速度 / 传球一般**,对手强 | **慢** — 控球降失误 |
| 球员 / 对手都**一般** | **均衡** — 默认 |
| **领先**(配合战术变化) | **慢** — 控球拖时间 |
| **落后** | **快** — 多打反击 |

---

## 二、球场宽度(pitchWidth)

**球场宽度 = 利用球场横向空间的偏好**,分 3 档:

### 窄(中央)

- **进攻方式**:**走中路**,**边路少用**
- **比赛特点**:中场密集,边路防守压力大但**中路控制力强**
- **适合**:
  - 球队**没有强力边锋** / 翼卫
  - 想要**中路渗透**(有强力前腰 / 中锋)
  - 5-3-2 之类中路密集阵

### 均衡

- 边路 / 中路 比例平均
- **默认**

### 宽(拉开)

- **进攻方式**:**走边路**,多传中
- **比赛特点**:**边路威胁大**,但**中路空虚** → 反击时容易被打穿
- **适合**:
  - 球队有 **强力边锋 / 翼卫**(DRIBBLER / CROSSER / SPEEDSTER)
  - **5-3-2 / 3-5-2** 之类需要翼卫插上的阵
  - 4-3-3 边路驱动

### 怎么选

| 你的情况 | 推宽度 |
|---|---|
| 边锋 / 翼卫 **强** | **宽** — 拉边路传中 |
| 边路 **弱**,中前场 **强** | **窄** — 走中路 |
| **强对弱** | **宽** — 拉开防线 |
| **弱对强** | **窄** — 收紧中路 |
| 都一般 | **均衡** — 默认 |

---

## 三、防线高度(defensiveLine)

**防线高度 = 后卫线在球场上的位置**,分 3 档。**这是 3 维度里影响最大的一档**,因为它直接决定**进攻压迫** vs **反击暴露**的 trade-off。

> **关于越位**:引擎里已经定义了高 / 中 / 低 对应的越位概率常量(1% / 4% / 15%),**但模拟逻辑目前未接入** — 也就是说**高线不会真的多吹越位**(链 [第 14 章](14-set-pieces.md) 越位段)。等接入后,这里会多一条 cost。本章下面讲的是**当前实际**效果。

### 低(缩后)

- **站位**:后卫线在自己禁区附近
- **比赛特点**:
  - **反击空间小**(对手反击要跑很远)
  - **进攻压迫弱**(抢回球要等对手压上)
- **适合**:
  - **弱对强** 防守反击
  - **领先后** 配合战术变化,稳守
  - 球队**速度慢**,不能上前

### 中(默认)

- 站位在球场中央
- **反击暴露 / 进攻压迫** 都平均
- **默认**

### 高(前压)

- **站位**:后卫线在中场附近
- **比赛特点**:
  - **反击暴露大**(身后空间大,对手长传 / 直塞很容易穿透)
  - **进攻压迫强**(抢回球快)
- **适合**:
  - **强对弱** 高压逼抢
  - 球队有 **高速 CB / 门将出击** (SWEEPER_KEEPER 特性)
  - 4-3-3 之类需要前场压迫

### 高线的真实 cost(目前)

**高线真正的 trade-off 是进攻压迫 vs 反击暴露,不是越位**:

- **高线** bonus:**进攻压迫强**,**夺回球快**
- **高线** cost:**身后空间大,被反击打穿容易失分**

> **未来**如果接入了越位模拟,会再加一条 cost:越位多。但**现在没有**。

如果你的 CB 速度慢,高线会被反击打穿;如果你的 CB 速度够,高线 + 高速边锋 = 机器。

### 怎么选

| 你的情况 | 推高度 |
|---|---|
| **强对弱** | **高** — 高压逼抢 |
| **弱对强** | **低** — 缩后防反 |
| **速度 CB** + **高速门将** | **高** — 高线后场追得上 |
| **速度慢 CB** | **低** — 防止被反击 |
| **领先** | **低** — 稳守 |
| **落后** | **中 / 高** — 给对手压力(但别冒进) |

## 四、3 维度怎么搭配(常见组合)

### 1. 平衡 / 通用(默认)

**均衡 / 均衡 / 中** — 哪边都不突出,适合大部分情况。

### 2. 高压逼抢(强对弱)

**快 / 宽 / 高** — 用速度和宽度碾压,高线前压让对手后场出球困难。

**前提**:球员速度高(W / CB / GK 都要有速度),前场压迫力强(DRIBBLER / SPEEDSTER / COMPOSED)。

### 3. 防守反击(弱对强)

**慢 / 窄 / 低** — 收紧中路,让对手在边路磨,后场密集堵死。

**前提**:中后场人数够,CB 位置感强(不需要速度,需要 TACKLER / WALL 特性)。

### 4. 控球消耗(领先)

**慢 / 均衡 / 低** — 拿到球慢慢传,不冒险,前场拖延时间。

**前提**:球队体力储备够,中场能拿住球(AM / CM 头牌传球高)。

### 5. 破釜沉舟(落后)

**快 / 宽 / 高** — 全压上,多打边路传中,前锋顶在最前。

**前提**:落后时间不太晚(70 分钟前),对手没锁死。

### 反组合(避免的搭配)

- **快 / 高** + **慢 CB** = 灾难,会一直被反击
- **慢 / 宽** + **没边锋** = 浪费宽度,边路没人
- **快 / 窄** = 反向矛盾(快应该走直塞或边路,窄强迫走中路,逻辑打架)

## 五、战术跟球员的关系

战术是**全队配置**;球员是**个体能力**。两个要匹配:

### 头牌能力 vs 战术要求

| 战术 | 你需要的头牌 |
|---|---|
| **快节奏** | SPEEDSTER W / COMPOSED CF / DRIBBLER AM |
| **慢节奏** | PLAYMAKER CM / TACKLER DM / 头牌传球高 |
| **宽阵** | CROSSER W / DRIBBLER 翼卫 |
| **窄阵** | PLAYMAKER AM / COMPOSED CF(走中路) |
| **高线** | 速度型 CB / SWEEPER_KEEPER GK |
| **低线** | TACKLER / WALL CB(位置感强) |

### 球员不够格怎么办

- **球员速度慢但战术想快** → 球员会**频繁失误**,快节奏反而吃亏
- **边锋弱但战术想宽** → 边路被针对,反而被打穿
- **CB 慢但战术想高** → 会被反击打穿,失球更多
- **结论**:**战术要跟着球员走**,不是反过来

## 六、提交与锁定

战术在每场比赛开始**前提交**,开赛就锁:

| 阶段 | 你能做什么 |
|---|---|
| **已安排** | 提交 / 修改战术(任意多次) |
| **战术已锁定**(开赛前 ~30 分钟,UI 自动锁) | **不能再改**,UI 倒计时 |
| **进行中** | 比赛中,战术已锁死,赛中不能改 |

> **锁定时间**:
> - **UI 锁**(编辑器变只读):开赛**前约 30 分钟**
> - **后端硬锁**(服务器拒绝新提交):开赛**前约 10 分钟**
>
> 这两个时间不一样,通常你看到 UI 锁了就别再试了。

**怎么避免错过锁定**:
- 比赛开始**前 1 小时**提交战术
- 用**预设**保存多套常用战术(见 [第 5 章](05-lineup-basics.md)),比赛前直接套用
- 提前看赛程,不要到点再补

## 七、战术变化(赛中触发)

战术风格是**赛前**定的。**赛中**(指定分钟 + 满足条件)还能触发**换人 / 移位**——见 [第 16 章](16-subs-and-orders.md)。

> 战术变化 ≠ 战术风格。战术风格是"踢法",赛中不变;战术变化是"赛中谁换下、谁换上、谁移位",按时触发。

## 八、跟其他概念的关系

| 概念 | 关系 |
|---|---|
| **阵容**(第 5 章) | 阵型 + 首发 + 替补 + 战术变化 = 一整套战术;战术风格是这一套里的"风格"部分 |
| **球员技能**(第 2 章) | 战术跟球员头牌要匹配(快节奏需要速度头牌) |
| **球员位置**(第 3 章) | 阵型选位置;战术风格定打法 |
| **specialties**(第 4 章) | 战术触发特性(快节奏 + SPEEDSTER = 反击机器;高线 + SWEEPER_KEEPER = 防线稳) |
| **比赛事件**(第 6 章) | 战术风格影响**所有**比赛事件的频率和分布(射门 / 反击 / 抢断...) |
| **定位球 / 越位**(第 14 章) | 防线高度**当前**只影响**进攻压迫 / 反击暴露**(越位逻辑未接入,详见第 14 章越位段) |
| **战术变化**(第 16 章) | 战术风格赛前定;战术变化赛中触发 |
| **战术预设**(第 5 章) | 保存反复用,比赛前直接套 |

## 九、常见错误

❌ **"快节奏一定好"**:**快 = 多失误**,球员速度不够时反而失分更多
❌ **"高线 = 越位多 = 战术失败"**:**目前高线不会真多吹越位**(模拟未接入),高线真正的 cost 是**被反击打穿**;未来接入越位后这条 trade-off 才完整
❌ **"宽阵 = 边路多"**:宽阵**需要强力边锋**,没边锋就等于没边路
❌ **"窄阵 = 死守"**:窄是**走中路**,不是死守;5-3-2 配窄 = 控球
❌ **"防线高度 = 比赛风格"**:防线高度是**进攻压迫 / 反击暴露** trade-off,不是踢法本身
❌ **"战术跟球员没关系"**:战术跟头牌**强相关**,强对弱 + 弱球员 = 浪费战术
❌ **"锁了还能改"**:UI 锁了就别再试,后端 ~10 分钟前就拒收
❌ **"3 维度独立"**:3 维度**互相影响**(快 + 高 + 慢 CB = 灾难;慢 + 低 + 强前锋 = 浪费)
❌ **"想赢就调高线"**:高线**不是必胜**,看球员速度 + 对手反击
❌ **"5 阵型都试一下"**:阵型决定位置,战术决定踢法;**先选好阵型(球员适合的位置),再调战术**

## 十、怎么用战术(实战流程)

### Step 1:看自己球员

- **速度头牌**? → 快节奏
- **传球头牌**? → 慢节奏 / 控球
- **强力边锋**? → 宽阵
- **强力前腰**? → 窄阵
- **速度 CB**? → 高线
- **位置感 CB**? → 低线

### Step 2:看对手

- **强对弱** → 高压(快 / 宽 / 高)
- **弱对强** → 防反(慢 / 窄 / 低)
- **差不多** → 默认(均衡 / 均衡 / 中)

### Step 3:看赛况

- **领先** → 慢 / 低(控球稳守)
- **落后** → 快 / 高(强攻,70 分钟前)
- **平局** → 默认

### Step 4:保存为预设

把几套常用战术存为预设(主场 / 客场 / 强敌 / 弱旅),比赛前直接套用,**不要每场都从头调**。
