# 比赛:战术

战术风格 = 你在**每场比赛开始前**设定的 2 个维度(球场宽度 / 防线高度),各 3 档,作用在**整支球队**的场上行为上。比赛已经开打,战术就锁死了,你不能赛中改。

第 5 章讲过**怎么提交战术**(UI / 预设 / 锁定),这一章讲**2 个维度各自怎么影响比赛**,以及**怎么根据对手和球员搭配**。

> 「比赛节奏」这个维度曾经存在,但已经**整体取消**了 —— 你在界面上不会再看到它,也不用再为它纠结。

---

## 2 个维度(快速参考)

| 维度 | 档位 | 关键作用 | 跟球员的关系 |
|---|---|---|---|
| **球场宽度**(pitchWidth) | 窄 / 均衡 / 宽 | 决定走**边路**还是**中路** | W 边锋 / LB 翼卫 在宽阵更舒服;AM 前腰 / CM 中场 在窄阵更舒服 |
| **防线高度**(defensiveLine) | 低 / 中 / 高 | 决定**进攻压迫**和**反击暴露**(越位逻辑未接入,目前不影响越位) | 高速 CB 在高线更舒服;慢速 CB 在低线更稳 |

> 2 维度**默认都是均衡**(球场均衡 / 防线中)。没想法就用默认。
> 想要更进一步的打法倾向,用[球队战术](28-team-tactics.md) —— 那是独立的一个选择。

---

## 一、球场宽度(pitchWidth)

**球场宽度 = 利用球场横向空间的偏好**,分 3 档:

### 窄(中央)

- **进攻方式**:**走中路**,**边路少用**
- **比赛特点**:中场密集,边路防守压力大但**中路控制力强**
- **适合**:
  - 球队**没有强力边锋** / 翼卫
  - 想要**中路渗透**(有强力前腰 / 中锋)
  - 5-3-2 之类中路密集阵

### 均衡

- 边路 / 中路 比例平均
- **默认**

### 宽(拉开)

- **进攻方式**:**走边路**,多传中
- **比赛特点**:**边路威胁大**,但**中路空虚** → 反击时容易被打穿
- **适合**:
  - 球队有 **强力边锋 / 翼卫**(DRIBBLER / CROSSER / SPEEDSTER)
  - **5-3-2 / 3-5-2** 之类需要翼卫插上的阵
  - 4-3-3 边路驱动

### 怎么选

| 你的情况 | 推宽度 |
|---|---|
| 边锋 / 翼卫 **强** | **宽** — 拉边路传中 |
| 边路 **弱**,中前场 **强** | **窄** — 走中路 |
| **强对弱** | **宽** — 拉开防线 |
| **弱对强** | **窄** — 收紧中路 |
| 都一般 | **均衡** — 默认 |

## 二、防线高度(defensiveLine)

**防线高度 = 后卫线在球场上的位置**,分 3 档。**这是 2 个维度里影响最大的一档**,因为它直接决定**进攻压迫** vs **反击暴露**的 trade-off。

> **关于越位**:引擎里已经定义了高 / 中 / 低 对应的越位概率常量(1% / 4% / 15%),**但模拟逻辑目前未接入** — 也就是说**高线不会真的多吹越位**(链 [第 14 章](14-set-pieces.md) 越位段)。等接入后,这里会多一条 cost。本章下面讲的是**当前实际**效果。

### 低(缩后)

- **站位**:后卫线在自己禁区附近
- **比赛特点**:
  - **反击空间小**(对手反击要跑很远)
  - **进攻压迫弱**(抢回球要等对手压上)
- **适合**:
  - **弱对强** 防守反击
  - **领先后** 配合战术变化,稳守
  - 球队**速度慢**,不能上前

### 中(默认)

- 站位在球场中央
- **反击暴露 / 进攻压迫** 都平均
- **默认**

### 高(前压)

- **站位**:后卫线在中场附近
- **比赛特点**:
  - **反击暴露大**(身后空间大,对手长传 / 直塞很容易穿透)
  - **进攻压迫强**(抢回球快)
- **适合**:
  - **强对弱** 高压逼抢
  - 球队有 **高速 CB / 门将出击** (SWEEPER_KEEPER 特性)
  - 4-3-3 之类需要前场压迫

### 高线的真实 cost(目前)

**高线真正的 trade-off 是进攻压迫 vs 反击暴露,不是越位**:

- **高线** bonus:**进攻压迫强**,**夺回球快**
- **高线** cost:**身后空间大,被反击打穿容易失分**

> **未来**如果接入了越位模拟,会再加一条 cost:越位多。但**现在没有**。

如果你的 CB 速度慢,高线会被反击打穿;如果你的 CB 速度够,高线 + 高速边锋 = 机器。

### 怎么选

| 你的情况 | 推高度 |
|---|---|
| **强对弱** | **高** — 高压逼抢 |
| **弱对强** | **低** — 缩后防反 |
| **速度 CB** + **高速门将** | **高** — 高线后场追得上 |
| **速度慢 CB** | **低** — 防止被反击 |
| **领先** | **低** — 稳守 |
| **落后** | **中 / 高** — 给对手压力(但别冒进) |

## 三、2 维度 + 球队战术怎么搭配(常见组合)

现在能调的东西是:宽度、防线,以及[球队战术](28-team-tactics.md)。下面是几套常见搭法。

### 1. 平衡 / 通用(默认)

**均衡 / 中**,不选球队战术 —— 哪边都不突出,适合大部分情况。

### 2. 强攻边路(强对弱)

**宽 / 高** + 双翼齐飞 —— 用宽度把人拉到边路,高线前压不让对手出球。

**前提**:边路球员(W / FB)是这个阵容里最强的一档。

### 3. 防守反击(弱对强)

**窄 / 低** + 防守反击 —— 收紧中路让对手在边路磨,后场密集堵死,断球后打身后。

**前提**:中后场人数够,CB 位置感强(不需要速度,需要 TACKLER / WALL 特性)。

### 4. 控球消耗(领先)

**均衡 / 低** + 传控压迫 —— 拿到球慢慢传,不冒险,前场拖延时间。

**前提**:球队体力储备够,中场能拿住球(AM / CM 头牌传球高)。

### 5. 破釜沉舟(落后)

**宽 / 高** + 高位逼抢 —— 全压上,多打边路传中,前锋顶在最前。

**前提**:落后时间不太晚(70 分钟前),对手没锁死。

### 6. 中路强攻

**窄 / 中** + 中路渗透 —— 把人堆在中路,靠直塞和突破撕开。

**前提**:中路人手够(DM / CM / AM 加起来至少 4 个)。

### 反组合(避免的搭配)

- **高线** + **慢 CB** = 灾难,会一直被反击
- **宽** + **没边锋** = 浪费宽度,边路没人
- **窄** + **没中路球员** = 中路堆不下,宽度也丢了

## 四、战术跟球员的关系

战术是**全队配置**;球员是**个体能力**。两个要匹配:

### 头牌能力 vs 战术要求

| 战术 | 你需要的头牌 |
|---|---|
| **宽阵** | CROSSER W / DRIBBLER 翼卫 |
| **窄阵** | PLAYMAKER AM / COMPOSED CF(走中路) |
| **高线** | 速度型 CB / SWEEPER_KEEPER GK |
| **低线** | TACKLER / WALL CB(位置感强) |

### 球员不够格怎么办

- **边锋弱但战术想宽** → 边路被针对,反而被打穿
- **中路没人但战术想窄** → 中路挤成一团,没有出球点
- **CB 慢但战术想高** → 会被反击打穿,失球更多
- **结论**:**战术要跟着球员走**,不是反过来

## 五、提交与锁定

战术在每场比赛开始**前提交**,开赛就锁:

| 阶段 | 你能做什么 |
|---|---|
| **已安排** | 提交 / 修改战术(任意多次) |
| **战术已锁定**(开赛前 ~30 分钟,UI 自动锁) | **不能再改**,UI 倒计时 |
| **进行中** | 比赛中,战术已锁死,赛中不能改 |

> **锁定时间**:
> - **UI 锁**(编辑器变只读):开赛**前约 30 分钟**
> - **后端硬锁**(服务器拒绝新提交):开赛**前约 10 分钟**
>
> 这两个时间不一样,通常你看到 UI 锁了就别再试了。

**怎么避免错过锁定**:
- 比赛开始**前 1 小时**提交战术
- 用**预设**保存多套常用战术(见 [第 5 章](05-lineup-basics.md)),比赛前直接套用
- 提前看赛程,不要到点再补

## 六、战术变化(赛中触发)

战术风格是**赛前**定的。**赛中**(指定分钟 + 满足条件)还能触发**换人 / 移位**——见 [第 16 章](16-subs-and-orders.md)。

> 战术变化 ≠ 战术风格。战术风格是"踢法",赛中不变;战术变化是"赛中谁换下、谁换上、谁移位",按时触发。

## 七、跟其他概念的关系

| 概念 | 关系 |
|---|---|
| **阵容**(第 5 章) | 阵型 + 首发 + 替补 + 战术变化 = 一整套战术;战术风格是这一套里的"风格"部分 |
| **球员技能**(第 2 章) | 战术跟球员头牌要匹配(宽阵需要边锋头牌) |
| **球员位置**(第 3 章) | 阵型选位置;战术风格定打法 |
| **specialties**(第 4 章) | 战术触发特性(高线 + SWEEPER_KEEPER = 防线稳) |
| **球队战术**(第 28 章) | 2 个维度调"往哪边偏",球队战术调"整队怎么打";两者叠加 |
| **比赛事件**(第 6 章) | 战术风格影响**所有**比赛事件的频率和分布(射门 / 反击 / 抢断...) |
| **定位球 / 越位**(第 14 章) | 防线高度**当前**只影响**进攻压迫 / 反击暴露**(越位逻辑未接入,详见第 14 章越位段) |
| **战术变化**(第 16 章) | 战术风格赛前定;战术变化赛中触发 |
| **战术预设**(第 5 章) | 保存反复用,比赛前直接套 |

## 八、常见错误

❌ **"高线 = 越位多 = 战术失败"**:**目前高线不会真多吹越位**(模拟未接入),高线真正的 cost 是**被反击打穿**;未来接入越位后这条 trade-off 才完整
❌ **"宽阵 = 边路多"**:宽阵**需要强力边锋**,没边锋就等于没边路
❌ **"窄阵 = 死守"**:窄是**走中路**,不是死守;5-3-2 配窄 = 控球
❌ **"防线高度 = 比赛风格"**:防线高度是**进攻压迫 / 反击暴露** trade-off,不是踢法本身
❌ **"战术跟球员没关系"**:战术跟头牌**强相关**,强对弱 + 弱球员 = 浪费战术
❌ **"锁了还能改"**:UI 锁了就别再试,后端 ~10 分钟前就拒收
❌ **"2 维度独立"**:2 维度**互相影响**(高线 + 慢 CB = 灾难;窄 + 没中路 = 白窄)
❌ **"想赢就调高线"**:高线**不是必胜**,看球员速度 + 对手反击
❌ **"5 阵型都试一下"**:阵型决定位置,战术决定踢法;**先选好阵型(球员适合的位置),再调战术**

## 九、怎么用战术(实战流程)

### Step 1:看自己球员

- **强力边锋**? → 宽阵
- **强力前腰**? → 窄阵
- **速度 CB**? → 高线
- **位置感 CB**? → 低线

### Step 2:看对手

- **强对弱** → 高压(宽 / 高)
- **弱对强** → 防反(窄 / 低)
- **差不多** → 默认(均衡 / 中)

### Step 3:看赛况

- **领先** → 低线(控球稳守)
- **落后** → 高线 + 宽阵(强攻,70 分钟前)
- **平局** → 默认

### Step 4:保存为预设

把几套常用战术存为预设(主场 / 客场 / 强敌 / 弱旅),比赛前直接套用,**不要每场都从头调**。
