# 球员:其他属性

技能(第 2 章)和位置(第 3 章)是球员的"硬指标",但场上表现还受一组**其他属性**直接影响。这章讲这些"软指标",重点说明每个属性**在比赛里具体起什么作用**:

- **PWI** — 综合分(供比价、球探、阵容总览)
- **currentSkills vs potentialSkills** — 雷达图双线
- **potentialTier** — 潜力档(LOW / REGULAR / HIGH_PRO / ELITE / LEGEND)
- **form** — 短期状态,影响比赛中**每一次关键动作**的表现
- **experience** — 长期积累,影响比赛中**每一次关键动作**的表现
- **stamina** — 球员的体力天赋
- **比赛中当前体能** — 比赛内剩余体力(看体力条)
- **injury** — 伤病状态(影响能否上场)
- **specialties** — 12 种 + GOLD / SILVER / BRONZE 三档强度
- **age** — 年龄(28+ 起触发技能衰退,详见下文)

> **核心理解**:**form、experience、比赛中当前体能三者,共同决定比赛内每次关键事件(进球、助攻、抢断、扑救、关键传球、过人...)的表现**。PWI 只是**比赛外的预估值**,真正的"场上发挥"看这三个。

## PWI — 综合分

**PWI = Player Worth Index** = 球员的综合分。雷达图旁边、球员卡、转会市场、球探报告里都看得到。

**PWI 由三个因素综合决定**(定性):

1. **currentSkills** — 主导。头牌技能高 → PWI 高
2. **潜力** — 放大因子。**同样技能下,潜力高的球员 PWI 上限更高**(潜力低的涨到顶也就那样)
3. **form** — 微调。form 高时 PWI 显示略高,form 低时略低

> **PWI 高 ≠ 场上一定好**。两个 PWI 相同的球员,放在不同位置踢,实际表现天差地别(位置权重不同)。看 PWI 永远要结合**位置**([第 3 章](03-positions.md))。

**什么时候看 PWI**:
- **转会市场比价** — PWI 是你**自己判断**的核心指标,但**起拍价是卖家自己设的**,跟 PWI 没有自动公式
- **球探报告** — 球探给的 PWI 范围,大概判断球员实力档
- **阵容总览** — 快速扫一眼球队核心球员的 PWI 分布

> **PWI ≠ 起拍价 / 工资**。起拍价由卖家手动设定;工资在球员**生成时**定(跟 age + 随机数有关,跟 PWI 没有直接公式)。PWI 高**可能**对应高工资(因为 generation 公式里 age 系数跟 PWI 上限间接相关),但**不是因果**。看 PWI 时**别**假设"PWI 高 = 一定贵"。

## currentSkills vs potentialSkills — 雷达图双线

雷达图上每项技能有 **2 条线**:
- **实线** = `currentSkills`(当前能力,场上实际表现)
- **虚线** = `potentialSkills`(潜力上限,涨到这就不长了)

**两线距离 = 还能涨多少**:
- **长成的球员**:两线几乎重合(已到顶)
- **未长成的球员**:差距大(还在长)

涨到 `potentialSkills` 就到顶(不会超过虚线)。**潜在技能的值由潜力决定**,currentSkills 涨到顶后停。

**怎么涨**:
- **比赛** — 比赛后按场上表现给技能 +1(在潜力范围内)
- **训练** — 周四按训练类别涨

详细见 [第 2 章](02-player-skills.md) "技能怎么涨"段。

## potentialTier — 潜力档

潜力标签(从低到高):**LOW / REGULAR / HIGH_PRO / ELITE / LEGEND**。跟**当前能力**无关,代表**球员的天花板**。

- **LOW**(灰)— 潜力低,练到顶也基本是替补
- **REGULAR**(绿)— 标准,大多数 outfield 主力水平
- **HIGH_PRO**(金)— 高潜,练满是顶级
- **ELITE**(金偏红)— 顶级潜力,极其稀有
- **LEGEND**(紫)— 现象级,几乎不出

**注意:potentialTier 跟雷达图上技能 / 经验显示的 tier 标签是两套不同的东西**:
- **potentialTier** = 潜力档,标在球员卡的"潜力"位置
- **tier 标签** = 技能 / 经验的等级档,标在雷达图每项技能旁 / 经验 badge 上
- **名字像,不是同一套**——别混

## form — 短期状态

**form = 短期状态**,**影响每场比赛的实时表现**。实际范围 **约 1-6**(系统 clamp 在 5.99,默认 3.0)。

### form 在比赛里做什么

每场比赛,form 决定一个**状态加成**,作用在**几乎所有比赛事件**的最终表现上(进球、助攻、抢断、扑救、关键传球、过人、争顶...):
- `form ≈ 3.5` → 状态加成 ≈ 0.95(sigmoid 中点,**最接近"无偏移"**)
- `form > 3.5` → 加成向 1.12 收敛(关键动作增强)
- `form < 3.5` → 加成向 0.78 收敛(关键动作衰减)
- form 5+ 持续很多场才是"明显好";1-2 持续很多场才是"明显差"

> form 不会给到严格 1.0 的"中性",只是靠近 3.5 时**最接近无偏移**。一场比赛 form 5.0 vs form 1.0 的两个球员,同样位置同样技能,前者进球 / 扑救的"评分"会系统性高于后者。

### form 怎么变

form 由后台 **每周四 00:00 UTC 的 condition-settlement 工人**统一结算,根据**累计上场分钟、球迷情绪、主教练水平、是否带伤** 这 4 个因素**向一个隐藏基线收敛**(加一点随机扰动)。**跟场上具体表现好坏无关,跟训练也无关**(训练只改技能,不动 form)。

实战含义:
- **上场时间长**(单场 60+ 分钟)→ form 隐藏基线 ≈ 3.5,容易维持 / 涨
- **没打比赛** → form 隐藏基线 ≈ 2.5,form 会慢慢往下掉(长期不打 = 失宠)
- **球迷情绪高** → form 隐藏基线略上调
- **带伤上场** → form 隐藏基线 -0.5(明显往下)

### form 跟 PWI 的关系

PWI 显示时也考虑 form(form 高时 PWI 显示略高,form 低时略低),但 **PWI 只是预估**——比赛内 form 对每次事件的加成才是 form 的**真实作用**。

### 怎么看

- 球员卡 / 雷达图上显示"状态箭头"(`↑ / → / ↓`)

### 什么时候看 form

- **短期决策**(这赛季争冠) → form 极重要,看 form 买人
- **长期决策** → form 波动可以忽略,看潜力 + 经验

## experience / 等级 — 长期"老练度"

**experience = 累计 XP**,每场比赛结束涨。**等级** 从 0 起,**无上限**(等级无封顶,显示封顶到 L20,见 [附录 3](A3-tier-labels.md))。

### experience 在比赛里做什么

每场比赛,experience 决定一个**经验加成**,作用在**几乎所有比赛事件**的最终表现上(进球、助攻、抢断、扑救、关键传球...):
- **0 XP → 加成中性**(无加成)
- **高 XP → 加成 > 1**(关键动作按比例增强)
- **增长放缓** — 经验越多加成越大,但**越往后增长越慢**(收益递减)
- **没有硬封顶**(等级 L20 显示封顶,但内部 XP 继续涨,加成继续接近上限,只是越来越慢)

**结论**:**经验高的球员 = 关键时刻的表现更优**。同样位置同样技能,老将比新秀在比赛事件上系统性更强。

### 升级成本

**线性**,每级 +2 XP:
- L0 → L1 需 10 XP
- L1 → L2 需 12 XP
- L2 → L3 需 14 XP
- ...
- L5 → L6 需 20 XP
- ...

### tier 标签

经验 ≥ 某个值时显示对应 tier(具体见 [附录 3](A3-tier-labels.md))。**L20 封顶显示**——内部等级还能继续涨,但 tier 标签不会超过 `L20 化境`。
- 鼠标悬停 → 看 raw XP
- L20 以上的球员,UI 看起来都标"化境",raw XP 用来区分

### 经验怎么涨(按比赛类型倍率)

- 国家队 **5x**(涨最快)
- 季后赛 2x
- 联赛 / 杯赛 1x(基准)
- 友谊赛 0.1x(几乎不涨)
- 锦标赛 0(不算)

踢满 90 分钟 = 拿满基础经验;踢 45 分钟只拿一半;替补 10 分钟几乎不涨。

### 老将点球红利(为什么 experience 高值钱)

**点球**用**专门的加成**,**只**看 form + experience,**不看比赛中当前体能**:
- **结论**:**老将踢点球更稳**——不会因为疲劳而失准,经验加成照常生效

### 为什么 experience 是长期价值

- 经验**不可逆**(不会掉)
- 比赛**每场都在涨**(即使替补 1 分钟)
- 越老的球员经验越高 → 场上关键时刻表现越稳
- **PWI 显示时也考虑 experience**(作为 PWI 预估的因子之一),但 PWI 只是预估,比赛内的经验加成才是真实作用

## stamina / 比赛中当前体能 — 比赛内体能曲线

**两个概念要分清**:
- **stamina** = 球员的"**体力天赋**",标在球员卡 / 雷达上
- **比赛中当前体能** = 比赛内**剩余体力**,看比赛直播的体力条

### 比赛中当前体能的完整生命周期

| 阶段 | 行为 |
|---|---|
| 比赛开始 | 当前体能 = stamina 天赋(每场满血) |
| 比赛中 | 持续消耗(跑动、对抗、扑救、动作都耗) |
| 中场 15 分钟 | **部分恢复**(少量) |
| 换人 | **新上场球员当前体能 = stamina 天赋**(100% 满血) |
| 比赛结束 | 当前体能丢弃,球员回到"满血"状态等下一场 |

### 当前体能(比赛中)在场上起什么作用

每场比赛,当前体能决定一个**体能加成**:
- **体能充足时**(消耗没到"热身期"结束)→ 加成 = 1.0(**满血表现**,场上动作不受影响)
- **透支时** → 加成**急剧下降**,消耗越多掉得越快
- 开赛一段时间有个"热身期":消耗到这个阶段之前,场上表现**不会**衰减(给球员一个开赛保护时间)

**结论**:
- **满血上场** → 场上表现不受影响
- **踢到下半场体能见底** → 表现急剧下降
- **中场换上来的球员** → 100% 满血上场,体能加成 = 1.0(适合补时强攻)

### stamina 天赋本身

- **stamina 不会因为比赛消耗而永久下降**——它是个"天赋",决定每场比赛的起始体力池和抗疲劳能力
- **stamina 高的球员** = 体力池大、**抗疲劳** → 比赛末段不容易崩
- 比赛之间 stamina 天赋**不变**(它是天赋,不是当前状态)

### 怎么看

- 比赛直播时,球员卡上显示**体力条**(绿色 / 黄色 / 红色)——这就是比赛中当前体能
- 实时变化,不用看雷达
- stamina 天赋本身在球员卡 / 雷达上以"stamina"标签显示

### stamina 跟 form / experience 的区别

- **stamina 天赋** = 球员的体力上限(每场的起点)
- **比赛中当前体能** = 本场剩余(临时状态)
- **form** = 跨比赛**短期状态**(影响每次动作)
- **experience** = **长期**积累(影响每次动作)

## injury — 伤病状态

球员有**当前伤病**状态,**3 档**:

| 状态 | 含义 | 表现 |
|---|---|---|
| 健康 | 没伤 | 正常出场 |
| **轻伤** | 可继续踢 | 能力下降(系统会判定) |
| **重伤** | 必须离场 | **强制换下**;有同位置替补就换人,没替补就 10 人应战 |

**2 档跟历史版本的区别**:历史版本有过"中度伤"档(必须离场),2026-08 起把中度合并入重伤(都是"必须离场",区别只在恢复天数 — 恢复时间由伤病值直接驱动,不再用 severity 区分)。所以现在场上**只看轻 / 重**2 档。

**伤病类型**(5 种):
- `muscle`(肌肉)
- `ligament`(韧带)
- `joint`(关节)
- `head`(头部)
- `other`(其他)

**伤病怎么产生**:
- 比赛事件触发(铲断 / 冲刺 / 跳跃 / 碰撞 / 过度使用,每场都可能发生)
- 触发概率跟**年龄、stamina、PHYSICAL_BEAST / AERIAL_THREAT 特性**有关(老将 / 低 stamina 更容易受伤)
- **每名球员每场最多触发 1 次**(引擎内部会去重)

**伤病怎么看 / 用**:
- 球员卡 / 详情页有"伤病"状态
- 重伤**不能进首发**(阵容按钮被锁)
- 重大伤病有"伤病记录"事件

**实战意义**:
- 买人前看伤病史(伤病记录事件多 = 玻璃人,慎买)
- 比赛日重伤强制换人;**没同位置替补就会送下场**(10 人应战)
- 轻伤球员上不上自己看(能力下降多少 = 风险)

## specialties — 12 种 + GOLD / SILVER / BRONZE

**specialties = 球员的"身份标签"**,影响特定比赛事件的加成。**12 种特性**,每种都对应一类事件加成。

### 12 种特性(适合位置 / 触发事件)

| 特性 | 中文 | 适合位置 | 触发事件 |
|---|---|---|---|
| `AERIAL_THREAT` | 空霸 | CB / CF | 头球、争顶 |
| `DRIBBLER` | 过人王 | W / AM | 1v1 过人 |
| `PLAYMAKER` | 组织者 | AM / CM | 直塞、最后一传 |
| `TACKLER` | 抢断王 | CB / DM | 抢断、铲断 |
| `WALL` | 铁墙 | CB / DM | 防守封堵 |
| `SPEEDSTER` | 快马 | W | 反击推进 |
| `CROSSER` | 传中王 | W / LB | 边路传中 |
| `POACHER` | 机会主义 | CF | 抢点、捡漏 |
| `COMPOSED` | 冷静 | CF / AM | 单刀处理 |
| `PHYSICAL_BEAST` | 野兽 | CB / CF | 身体对抗 |
| `SAVING_MASTER` | 扑救大师 | GK | 关键扑救 |
| `SWEEPER_KEEPER` | 出击型门将 | GK | 出击封堵 |

**强度档**:
- **GOLD**(金)— 加成最大
- **SILVER**(银)— 中等
- **BRONZE**(铜)— 最小

**特性关键事实**:
- **~50% 球员没有特性**(另一半随机分配;GK 只 ~10%)
- **强度跟技能无关** — 是生成时随机定的
- **多个同特性球员会叠加,不是只取最强** — 场上每个匹配的球员都按他的 tier 给加成,**深度叠加**(所以"广撒网"配 3 个 Silver 经常比 1 个 Gold 强)
- **跟位置/战术挂钩** — 跟战术搭配的 specialty 是 bonus

**实战意义**:
- 头牌 + 强特性 = 真核心
- GOLD 特性值溢价
- 找特定位置时看**对应位置的最佳特性**:
  - W 找 `DRIBBLER` / `SPEEDSTER` / `CROSSER`
  - CB 找 `TACKLER` / `AERIAL_THREAT` / `WALL` / `PHYSICAL_BEAST`
  - AM 找 `PLAYMAKER` / `DRIBBLER` / `COMPOSED`
  - CF 找 `POACHER` / `AERIAL_THREAT` / `COMPOSED` / `PHYSICAL_BEAST`
  - GK 找 `SAVING_MASTER` / `SWEEPER_KEEPER`

## age — 年龄

**`age` = 球员年龄**(整数)。

**重要事实**:**GoalXI 有年龄衰退机制**。从 **28+ 岁**开始,后台会按周跑一次 sub-quadratic 衰退曲线(物理类技能先掉,setPieces 几乎不掉;周一结算)。衰退有 **floor(每项技能最低 5)** — 35 岁是**最高 physical 技能触底**的拐点,不是"开始衰退"。

**衰退的实际节奏**(顶层定性):
- **17-28 岁** — 黄金期,技能不会因年龄掉
- **28-32 岁** — 物理类开始轻微掉,其他基本不动
- **32-35 岁** — 物理 / 技术类掉得明显,mental / setPieces 慢
- **35+ 岁** — 物理类触底,mental 仍可撑,setPieces 几乎不掉

**age 跟其他属性的关系**:
- **跟 experience 正相关** — 踢得久经验自然高(老将 = 高经验)
- **28+ 岁** 触发后台衰退系统,直接减 `currentSkills` 各项(不超 floor)
- **跟 form** 无直接关系

**age 唯一作用**:
- 显示在球员卡 / 详情页(让你知道球员多"老")
- **28+ 岁触发后台技能衰退**(每周一跑)
- 长期规划参考(年轻 = 还有潜力 + 还在黄金期;老 = 经验红利 + 衰退 trade-off)

> **GoalXI 的年龄衰退比 Hattrick 早、比 FM 缓**。老将**不会**"突然崩",而是从 28 起慢慢往下掉,35 岁是 peak 物理技能的拐点。28 岁前老将 = 红利期;30-32 = 经验 + 仍可首发;33+ = 慎重续约。

## 属性总览

| 属性 | 类型 | 在比赛里做什么 | 在比赛外做什么 | 在哪看 |
|---|---|---|---|---|
| **PWI** | 综合 | (不直接参与比赛,是预估值) | 转会比价、球探报告、阵容总览 | 球员卡、转会市场、雷达图旁 |
| **currentSkills** | 当前 | 关键事件的**基础评分**(被 form / experience / 当前体能 加成) | 雷达图实线 | 雷达图实线 |
| **potentialSkills** | 潜力上限 | (不直接参与,决定 currentSkills 涨到顶的位置) | 雷达图虚线 | 雷达图虚线 |
| **potentialTier** | 潜力档 | (不直接参与) | 长期价值判断 | 球员卡"潜力"位置 |
| **form** | 短期状态 | **状态加成**,作用在所有关键事件 | PWI 显示微调 | 球员卡"状态箭头" |
| **experience** | 长期积累 | **经验加成**(增长放缓),作用在所有关键事件;点球**只看 form + exp 不看当前体能** | PWI 因子;tier badge | 球员卡"EXP" + tier 标签 |
| **stamina** | 球员天赋 | 决定每场**起始体力池 + 抗疲劳能力** | 球员卡"stamina"标签 | 球员卡 stamina |
| **比赛中当前体能** | 比赛内临时 | **体能加成**,满血 = 中性,透支时**急剧下降** | (不持久) | 比赛直播体力条 |
| **injury** | 伤病状态 | 轻伤 = 能力下降(可上场),重伤 = 强制离场(不可首发) | 锁首发 / 伤病记录事件 | 球员卡"伤病"位置 |
| **specialties** | 特性 | 特定事件的加成,**多球员同特性会叠加** | 球员卡"特性"位置 | 球员卡"特性"位置 |
| **age** | 数值 | 28+ 触发后台技能衰退(物理类最快,setPieces 最慢) | 衰退系统开关;长期规划参考 | 球员卡"年龄"位置 |

## 常见错误(关于属性)

❌ **PWI 高 = 强球员**:**PWI 高只是综合分高**,头牌不对位置 = 场上隐身
❌ **PWI 高 = 起拍价/工资一定高**:**PWI 跟价格没有直接公式**,起拍价卖家自己设,工资 generation 时定
❌ **不看 potentialSkills 差距**:**潜力高不等于还能涨**,看 currentSkills 跟 potentialSkills 的 gap
❌ **追 perfect 球员**:**LEGEND + 满技能 + 健康 + 年轻 + 便宜 = 不存在**
❌ **忽视 form 波动**:**form < 1.5 时买便宜**(伤后恢复期,可能反弹)
❌ **把 potentialTier 跟 tier 标签混**:**潜力档 ≠ 等级档,两套**
❌ **以为 age 没影响 / 35+ 才掉技能**:**28+ 就开始衰退**;35 岁只是 peak physical 触底的拐点
❌ **GK 看 pace / strength / 定位球**:**没用**,pace / strength / 定位球对 GK 表现没影响
❌ **轻伤当没事上**:**能力下降**,关键比赛别赌
❌ **只追 GOLD 特性**:**没有特性 + 头牌高 > GOLD 特性 + 头牌低**(且多 Silver 叠加常强过 1 Gold)
❌ **新秀当老将用**:**0 XP = 经验加成中性(无加成)**,同样技能下老将关键时刻更稳
❌ **忽视 stamina 低的球员**:**stamina 低 → 抗疲劳弱 → 比赛末段容易崩**,关键场次慎用
