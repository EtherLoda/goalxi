# 联赛级别系统

GoalXI 的联赛 = **4 级金字塔**,每级 16 队,共 **85 个联赛 / 1360 队**。你的球队在赛季初被分配到 L4-L1 中的某一级,赛季打完按排名升级 / 降级。

这一章讲**金字塔结构、积分榜、升级 / 降级、赛季节奏**。**杯赛**见 [第 21 章](21-cup-system.md)。

---

## 一、金字塔结构(4 级)

| 级别 | 中文名 | 联赛数 | 区数 | 球队数 / 区 | 总队数 |
|---|---|---|---|---|---|
| **L1** | 中国超级联赛 | 1 | 第 1 区 | 16 | 16 |
| **L2** | 中国甲级联赛 | 4 | 第 1-4 区 | 16 | 64 |
| **L3** | 中国乙级联赛 | 16 | 第 1-16 区 | 16 | 256 |
| **L4** | 中国业余联赛 | 64 | 第 1-64 区 | 16 | 1024 |
| **合计** | | **85** | | | **1360** |

> **区归属**:
> - L2 第 1-4 区都挂 L1(每个 L2 区 = L1 的子联赛)
> - L3 第 1-4 区挂 L2 第 1 区,L3 第 5-8 区挂 L2 第 2 区...L3 第 d 区挂 L2 第 `ceil(d/4)` 区
> - L4 同理,每 4 个 L4 区挂同一个 L3 区
> 
> 升级 / 降级**只在相邻两级之间**发生(L1 ↔ L2 / L2 ↔ L3 / L3 ↔ L4)。

---

## 二、赛季节奏

- **每赛季 16 周**(赛季长度 = 7 天/周 × 16 周)
- **联赛比赛在周三 + 周六**(cadence),每天 **6:00 UTC = 14:00 北京时间** 开球
- **杯赛在周二 + 周四**(链 [第 21 章](21-cup-system.md))
- **联赛 + 杯赛不冲突**:周一周日留给训练 / 财政结算 / 球探 / 球员成长

> 实战感知:你**每周打 1-2 场联赛**(具体看赛程密度)+ 杯赛轮次(如果你还在杯赛中),其他天用来**调整阵容、训练、转会操作**。

---

## 三、联赛内有什么

每个联赛是一个独立的"赛季循环",**不跨联赛**。

| 字段 | 含义 | MVP 默认值 |
|---|---|---|
| `name` | 联赛名 | "中国超级联赛" / "中国甲级联赛 第 N 区" / ... |
| `tier` | 1 = 顶级,2-4 = 依次降低 | 1 / 2 / 3 / 4 |
| `tierDivision` | 同级内的区编号 | L2: 1-4,L3: 1-16,L4: 1-64 |
| `maxTeams` | 最大球队数 | **16** |
| `parentLeagueId` | 所属上级联赛 | L4 挂 L3,L3 挂 L2,L2 挂 L1 |
| `status` | 联赛状态 | `active` / `inactive` |

> **每联赛 16 队**(主客场双循环 = 30 轮比赛 = **30 场比赛** / 队 / 赛季)

---

## 四、升降级(每个联赛都一样)

每个赛季末,**前 1 + 中间 4 + 后 4 = 9 个名次**跟升降级有关:

| 名次 | 结局 | 说明 |
|---|---|---|
| **1 名** | **直接升级**到上级联赛 | 升 1 个队 |
| **2-8 名** | **不动** | 留在原级 |
| **9-12 名** | **打升降级附加赛** | 4 个队 vs 对应上级联赛的 9-12 名,**胜者升 / 留,负者留 / 降** |
| **13-16 名** | **直接降级**到下级联赛 | 降 4 个队 |

> **净流量检查**:L1 升 1 / 降 4 = 净流出 3,但 L1 是顶级没有下级(没有 L0),所以**顶级联赛 L1 不会从 L0 升人**,L1 的 4 个降级会进入 L2 的 4 个升级位(系统保持总人数恒定)。
>
> L2 / L3 / L4 是**平衡流** — 升级 = 降级数(净 0)。

**升降级附加赛的细节**:
- 9-12 名 vs 上级联赛 9-12 名,**单场淘汰**
- 赛制跟杯赛类似(链 ch 21),**主客场两回合**(链 ch 6)
- 胜负规则:积分 / 客场进球 / 加时 / 点球(链 [第 6 章](06-match-basics.md))

> **实战意义**:
> - **稳定在 1-8 名 = 留在原级** — 不用担心
> - **9-12 名 = 进入附加赛** — 紧张但有救
> - **13 名以后 = 必降级** — 下一赛季踢下级联赛

## 五、积分榜(League Standings)

每联赛每赛季一个积分榜,按以下顺序排序:

```
积分 (points) → 净胜球 (goalDifference) → 进球数 (goalsFor)
```

| 字段 | 含义 |
|---|---|
| `position` | 排名(1 = 榜首) |
| `played` | 已赛场次 |
| `wins` / `draws` / `losses` | 胜 / 平 / 负场次 |
| `goalsFor` | 进球数 |
| `goalsAgainst` | 失球数 |
| `goalDifference` | 净胜球(进球 - 失球)**计算后填** |
| `points` | 积分(**胜 3 / 平 1 / 负 0**) |
| `recentMatches` | 最近 5 场比赛的 W/D/L + 比分 + 对手(动态算) |

**怎么看积分榜**:
- **榜首争夺** = 积分榜前 2,通常在赛季末几周定冠
- **升降级线** = 9-12 名是"附加赛区",13 名开始"降级区"
- **净胜球**是同分时**最重要的 tie-breaker**(进得多比失得少好)
- **进球数**是净胜球相同时的 tie-breaker

**怎么看最近状态**:
- `recentMatches` 是 FE 动态算的,显示**最近 5 场**的 W/D/L
- 状态好 = 连胜,状态差 = 连败,中游 = 胜负交替

## 六、怎么用 API 拿数据(都是**公开**端点)

| 端点 | 用途 | 关键参数 |
|---|---|---|
| `GET /leagues` | 列所有联赛(分页) | `page`, `limit` |
| `GET /leagues/:id` | 单联赛 meta | `id` (UUID 或 name) |
| `GET /leagues/:id/standings` | 积分榜 | `season` (默认 1) |
| `GET /leagues/:id/seasons` | 该联赛有数据的赛季列表(降序) | — |

> **赛季 (season)** 是 int,从 1 开始。MVP 默认 `season=1`,多赛季后会累加。

## 七、赛季流程(总览)

```
第 1 周 ──── 联赛第 1-2 轮 ────→ 第 2 周 ──── 联赛第 3-4 轮 ────→
   ↓                                                              ↓
   ... 14 周 + 2 个 buffer ─────────────────────────────────────
                                                              ↓
第 16 周 ──── 联赛第 30 轮 ──── 收官 ────→ 升降级 ────→ 下一赛季
```

| 阶段 | 时长 | 你能做什么 |
|---|---|---|
| **赛季中**(第 1-15 周) | 15 周 | 看积分榜、提交战术、参加比赛、买人卖人 |
| **赛季末**(第 16 周) | 1 周 | 收官、附加赛 |
| **间歇期** | 几天 - 1 周 | 升级 / 降级结算、新赛季 schedule 生成 |
| **下一赛季** | 立即开始 | 球队可能在**新联赛**(L1→L2 或 L2→L1) |

> **赛季没"草稿"或"预生成"的概念** — schedule 在赛季开始前一次性生成,30 轮全在第一周就排好(你能在 matches list 看到完整赛程)。

## 八、跟其他概念的关系

| 概念 | 关系 |
|---|---|
| **球队**(team) | 球队在**1 个联赛**里(创建时分配),每赛季踢 30 场 |
| **比赛**(第 6 章) | 联赛比赛有 `leagueId` 字段,标识属于哪个联赛;非联赛比赛(杯赛)有 `cupId` 字段 |
| **杯赛**(第 21 章) | 杯赛是跨联赛的(National Cup = L1-L4 全部参加),**独立**于联赛 |
| **球员**(第 4 章) | 球员的**当前联赛** = 他所在球队的联赛;球员**不**自己带联赛归属 |
| **转会**(第 18 章) | 转会**跨联赛**目前**不支持**(同联赛内才行) |
| **青年**(第 19 章) | 青年球员属于哪个联赛 = 他**所属球队**的联赛 |
| **财政**(第 9 章) | 排名奖金 = 赛季末按排名发,**详见下节** |

## 九、排名奖金(每赛季末)

赛季末按最终排名发一笔"赛季排名奖",激励大家冲击 L1 / 保级:

| 名次 | 奖金量级(粗略) | 备注 |
|---|---|---|
| **1 名(冠军)** | 大 | L1 >> L2 >> L3 >> L4(低级别冠军奖励小) |
| **2-4 名(亚军 + 季军)** | 中大 |  |
| **5-8 名(中游)** | 中 |  |
| **9-12 名(附加赛区)** | 小 | 钱少但**没降级** |
| **13-16 名(降级区)** | 0 或负 | **降级本身**可能扣财政(下级联赛赞助少) |

> 具体数字按联赛等级 + 当前赞助合同算,链 [第 9 章](09-finance.md)。**MVP 阶段是粗略量级**,精确数字看 finance 页的 TransactionHistory 详情。

## 十、跟比赛类型 / 经验的关联(链第 6 章 + 第 4 章)

联赛比赛给球员的经验按**完整 90 分钟**结算,**倍率 1.0×**(基准):

| 比赛类型 | EXP 倍率 | 你在联赛里吗? |
|---|---|---|
| **联赛** | **1.0×**(基准) | ✅ |
| **杯赛** | 1.0× | 链 ch 21 |
| **季后赛** | 2.0× | 不是联赛,但赛季后打 |
| **国家队** | 5.0×(涨最快) | 不是联赛 |
| **锦标赛** | 0(不算) | 不是联赛 |
| **友谊赛** | 0.1× | 不是联赛 |

> **联赛是球员经验的主要来源**(踢满 30 场 = 30 单位 XP,大概涨 2-3 级)。

## 十一、能做 / 不能做

### ✅ 能做

- 看任何联赛的积分榜(公开)
- 看自己球队在联赛中的位置、战绩、积分
- 看最近 5 场比赛的表现(recentMatches)
- 跨赛季看历史积分榜(用 `?season=N`)
- 看哪些赛季有数据(`/leagues/:id/seasons`)

### ❌ 不能做(玩家侧)

- **手动建 / 改 / 删联赛** — `POST /leagues` / `PATCH /leagues/:id` / `DELETE /leagues/:id` 是 admin 端点,玩家没权限
- **换联赛** — 球队创建时锁死 L 等级,只能靠升降级跨
- **升降级人工触发** — 赛季末**自动**结算
- **改 maxTeams / promotionSlots** — 联赛规则**硬编码**到赛季生成器
- **跨联赛转会** — 同联赛内才能买人(链 ch 18)

### ❌ 不能做(也是 MVP 限制)

- **不存在的级别** — 目前**只有 L1-L4**,没有 L0 / L5 / L6 (L0 不需要 — L1 是顶级;L5 / L6 留作 future)
- **没有"平级区之间"的升降级** — L2 第 1 区不会和 L2 第 2 区互调(只有上下级之间)
- **没有季后赛制度** — "playoff_slots" 字段是给**附加赛**(9-12 名之间)用,不是赛季末 playoffs

## 十二、常见错误(关于联赛)

❌ **"第 9 名 = 升级"**:9-12 名是**附加赛**名次,**不是直接升级**,要打附加赛
❌ **"第 13 名 = 降级"**:13 名**直接降级**,**没附加赛机会**
❌ **"净胜球不重要"**:同分时**净胜球是首要 tie-breaker**(进球 - 失球),第 1 名 vs 第 2 名可能就靠这个
❌ **"L1 冠军 = 全国冠军"**:L1 冠军 = L1 联赛冠军。**真正的全国冠军是 National Cup**(链 ch 21)
❌ **"30 场要打 30 周"**:30 场压缩到 16 周里,实际**一周打 2 场**(周三 + 周六)
❌ **"升降级看 PWI"**:升降级看**赛季战绩**(积分 + 净胜球 + 进球),**不**看 PWI
❌ **"L1 升到 L0"**:L1 **就是顶级**,没有 L0。L1 降级是去 L2
❌ **"参赛球队会变"**:**1360 队是固定的**(赛季生成时一次性写入);新赛季**不**有新队加入(也不剔除)
❌ **"升到 L1 就完了"**:升 L1 是赛季目标,但**还有杯赛** — 链 ch 21

## 十三、实战流程(球队经理视角)

### 你的赛季目标(按联赛级别)

| 你的级别 | 现实目标 |
|---|---|
| **L4** | 升级到 L3(单赛季前 1 + 4 附加,概率高) |
| **L3** | 升级到 L2(竞争激烈,前 1 + 4 附加) |
| **L2** | 进 L1 附加赛(9-12 名) → 升 L1 |
| **L1** | 保级(13-16 名外) → 长期目标:杯赛夺冠 |

### 一周节奏(典型)

| 日 | 事件 |
|---|---|
| **周一** | 训练 / 财政 / 阵容调整(没比赛) |
| **周二** | **杯赛**(如果你还在杯赛中) |
| **周三** | **联赛** |
| **周四** | **杯赛** |
| **周五** | 训练 / 阵容调整 |
| **周六** | **联赛** |
| **周日** | 训练 / 阵容调整 / 看积分榜变化 |

### 看积分榜的频率

- **赛季初** — 看一眼排名,主要看**自己位置**和**前 8 名对手**
- **赛季中** — 每周看 1-2 次,关注**净胜球**和**进球数**(tie-breaker)
- **赛季末** — 每天看,**关键看 9-12 名**(附加赛区)
- **附加赛** — 必须看,这是升降级的临门一脚

### 跟对手的关键决策

- **前 4 名对手** = 直接竞争对手,**重点研究**(看他们的 PWI / 战术 / 状态)
- **5-8 名对手** = 中游,关系不大
- **9-12 名对手** = **附加赛直接对手**,**重点研究**(你跟他们打决定升降级)
- **13 名以后对手** = 你的"提款机",赢他们拿净胜球(可能决定 tie-breaker)
