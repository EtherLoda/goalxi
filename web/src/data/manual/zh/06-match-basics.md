# 比赛:基本信息

比赛是 GoalXI 的核心。每场联赛、杯赛、季后赛、友谊赛都按同一套流程走:比赛信息、比赛中事件流、比赛时钟、赛后报告。

这一章讲**你能在比赛中看到什么**。怎么排阵容见 [第 5 章](05-lineup-basics.md),战术怎么调见 [第 15 章](15-tactics.md),怎么换人见 [第 16 章](16-subs-and-orders.md)。

---

## 比赛状态(生命周期)

每场比赛按状态走:

```
已安排 → 战术已锁定 → 进行中 → 已结束
```

| 状态 | 含义 | 你能做什么 |
|---|---|---|
| **已安排** | 比赛已生成,未开赛 | 提交 / 修改战术 |
| **战术已锁定** | 临近开赛,战术不能再改 | 等待开赛 |
| **进行中** | 比赛在跑 | 看直播 |
| **已结束** | 比赛打完了 | 看报告、查属性变化 |

极少数情况会出现**已取消**(例如某队弃权后比赛被撤销)。

## 比赛基本信息(进比赛页能看到)

打开一场比赛,你能看到这些**赛前信息**:

- **开球时间** — 比赛哪天几点开
- **场地** — 主场 / 客场(主场在你自己的球场)
- **天气** — 晴 / 阴 / 雨 / 风 / 雾 / 雪,影响比赛风格(雨雪天气皮球更滑、传球更飘)
- **现场观众** — 球迷到场人数
- **主客队** — 谁是主队(列在左)谁是客队(列在右)
- **双方阵型** — 自动按各自的首发算出来(见 [第 5 章](05-lineup-basics.md))
- **双方首发 + 替补** — 11 + 6 + 6
- **赛事类型** — 联赛 / 杯赛 / 锦标赛 / 友谊赛 / 国家队 / 季后赛

> 开赛前 5 分钟左右,页面会显示**双方球员入场**的公告,正式进入直播界面。

## 比赛中能看到什么

进入直播后,核心信息分四块:

### 实时比分

- 左上角 / 右上角显示主队 vs 客队比分
- 进球即时更新(进 1 球比分 +1)
- 比赛结束定格最终比分

### 比赛时钟

**时钟随比赛推进自动走**,跟真实比赛一样:

- **上半场**:第 1 分钟到第 45 分钟(走完 45 分钟真实时间)
- **上半场补时**:**+N 分钟**(N 在比赛中确定,通常 1-5+ 分钟)
- **中场休息**:**15 分钟**(时钟停在补时最后一刻)
- **下半场**:第 46 分钟到第 90 分钟(中场休息后从 46 重新起)
- **下半场补时**:**+N 分钟**
- **加时**(平局需要决出胜负时):第 91 分钟到第 120 分钟
- **加时上下半场之间**:又一个 5 分钟休息
- **罚点球**(加时还平):在比赛页会显示点球决胜

**怎么看**:
- 直播页顶部会显示当前分钟(如 `45+2'`、`67'`、`90+5'`)
- 补时用 `+N` 表示
- 时钟走完 90 分钟(或加时)比赛进入"已结束"

### 实时解说(文字直播)

每次场上发生重要事件,**解说会立刻更新**一段文字描述:

- 谁做了什么动作(进球、扑救、犯规...)
- 用了什么方式(头球、单刀、远射、任意球...)
- 在哪个区域(左路 / 中路 / 右路)
- 谁助攻、谁防守
- 是否进球 / 是否被扑 / 是否罚失

**例子**:
- "球进了!{球员} 为{队} 拔得头筹!"
- "{球员} 在左路带球突破,晃过后卫,{质量}低射破门!"
- "{门将} 神扑!飞身单掌将{球员}的头球拒之门外!"
- "中场哨响!{队} {比分} 暂时领先。"

### 时间轴(关键事件)

时间轴是**按时间顺序排列的关键事件列表**,从开赛到结束,一屏看完全部:

- 每个事件:时间 + 球员 + 简短描述
- 进球 / 换人 / 牌 / 受伤会用不同颜色 / 图标
- 越位、犯规、角球通常**不**进时间轴(频率太高)

## 比赛中的事件类型

场上事件分成几大类,你会看到:

### 射门类(高频)

| 事件 | 含义 |
|---|---|
| **进球** | 球进了(普通进球) |
| **点球进球** | 12 码点球罚入 |
| **乌龙球** | 不幸进自家球门 |
| **扑救** | 门将把射门扑出来(没进) |
| **射偏** | 射门偏出 / 被挡 / 解围(没进) |
| **罚失点球** | 12 码点球没进(射偏或被扑) |

**射门方式**会显示:头球 / 单刀 / 远射 / 补射 / 普通射门。

**射门区域**:左路 / 中路 / 右路。

### 牌类(犯规处罚)

| 事件 | 含义 |
|---|---|
| **黄牌** | 警告(累计 2 黄变红) |
| **第二张黄牌 → 红牌** | 同一球员本场第 2 张黄,罚下 |
| **红牌(直接)** | 严重犯规,直接罚下 |

被罚下的球员**不能继续比赛**,球队少一人应战。

### 换人

- 战术预设的**换人**(见 [第 5 章](05-lineup-basics.md))在指定分钟触发
- **受伤换人**也会自动发生(系统判轻伤还能踢、重伤必须换)
- 时间轴会显示:换下谁、换上谁

### 受伤

- 比赛中触发:**铲断受伤 / 过度使用受伤**
- 状态分两档:**轻伤**(还能踢,能力下降)/ **重伤**(强制换下;有同位置替补就换人,没替补就 10 人应战,详见 [第 4 章](04-player-attributes.md))

### 定位球

| 事件 | 含义 |
|---|---|
| **角球** | 球被防守方碰出底线,进攻方在角旗区开球 |
| **任意球** | 犯规判罚,定点开球 |
| **直接任意球** | 可以在犯规点直接射门 |

> 定位球本身**一般不进时间轴**(太频繁),但如果直接任意球进了会显示"进球"。

### 越位

- 越位会触发,但**不一定每场都在时间轴里**(FE 通常不显示)
- 重要比赛会有专门的越位统计

### 比赛阶段

- **中场** — 上半场结束(45+N1 分钟后),休息 15 分钟
- **全场** — 90+N2 分钟后常规时间结束
- **加时上下半场** — 91-105 / 106-120
- **点球决胜** — 加时还平,罚 12 码决出胜负

### 元事件(开赛信息)

开赛前会有几个**说明性事件**(显示在比赛页,不在时间轴):

- **入场介绍** — "双方球员就位!{主队} {人数} vs {客队} {人数} 名球员"
- **天气公告** — "{今天天气}"
- **现场观众** — "现场观众 {N} 人"

## 比赛流程节奏(总览)

| 阶段 | 时长 | 时钟范围 |
|---|---|---|
| 上半场 | 45 分钟 | 1' - 45' |
| 上半场补时 | 1-5+ 分钟 | 45+1' - 45+N' |
| 中场休息 | 15 分钟 | 时钟停在 45+N |
| 下半场 | 45 分钟 | 46' - 90' |
| 下半场补时 | 1-5+ 分钟 | 90+1' - 90+N' |
| 加时上半场(需要时) | 15 分钟 | 91' - 105' |
| 加时下半场(需要时) | 15 分钟 | 106' - 120' |
| 点球决胜(需要时) | 罚 5 轮,平再各 1 轮 | 比赛结束后 |

**常规联赛 / 杯赛**:打满 90 分钟,平局直接结束(各拿 1 分 / 视规则)
**需要决出胜负**(杯赛 / 季后赛):平局进加时,加时还平就点球

## 信息差(fog of war)

**比赛双方看到的信息不完全一样**:
- **你方的事件**:即时显示(进球、扑救、犯规、换人)
- **对方的事件**:可能要延迟才显示(或部分隐藏),尤其是对方在另一侧半场的细节
- **统计数字**(控球率、射门次数等):赛后双方都能看
- **已结束的比赛**:信息全开,可以看全部事件流

> 这种"信息差"是为了体现真实足球中"球迷在主场看电视只能看主队摄像机"的体验。**不依赖这个做战术决策**——比赛已经按你的阵容 + 战术预设走完了。

---

## 弃权

**一方无法出场比赛**(极少见):系统判定对方不战而胜。

- 比分解读:**3-0 判胜**,胜方拿到 3 分(联赛积分)
- 时间轴会有"**{队} 弃权**"的说明
- 弃权方**不获得任何经验 / 球员成长**

---

## 比赛类型(6 种)

| 类型 | 含义 | 备注 |
|---|---|---|
| **联赛** | 常规积分赛,主客两回合 | 胜 3 分 / 平 1 分 / 负 0 分 |
| **杯赛** | 单场淘汰,平局进加时 / 点球 | 胜者晋级,败者出局 |
| **锦标赛** | 多队短期杯赛 | 视赛事规则 |
| **友谊赛** | 练习性质,不影响积分 | **当前没有玩家侧流程** |
| **国家队** | 球员代表国家队出战 | 经验倍率最高(5x) |
| **季后赛** | 升降级附加赛 | 视赛事规则 |

> 不同比赛类型的经验值倍率见 [第 4 章](04-player-attributes.md)。

## 比赛结束后

比赛进入"已结束"状态后:

- **比分定格**,时间轴冻结
- **比赛报告**:数据统计(左 / 中 / 右三路进攻比例、xG 预期进球、控球等)
- **球员属性变化**:
  - **技能**:按场上表现 +1(在潜力范围内,见 [第 2 章](02-player-skills.md))
  - **经验**:按比赛时长 + 类型倍率涨(见 [第 4 章](04-player-attributes.md))
  - **状态 / form**:表现好涨,表现差跌
  - **伤病记录**:重大伤病会留痕
- **联赛积分更新**(胜 +3 / 平 +1 / 负 +0)
- **下一场对手**:看积分榜 / 赛程

## 常见错误(关于看比赛)

❌ **"为什么看不到对方的事件?"**:信息差是设计,**只能看你方即时细节**,对方半场细节可能要等
❌ **"时钟不动"**:中场休息 15 分钟,时钟会停,**不是 bug**
❌ **"为什么 90 分钟了还在打"**:补时阶段,等裁判吹哨
❌ **"怎么没看到越位"**:越位频繁,**不进时间轴**,只是统计数字
❌ **"弃权怎么算"**:3-0,胜方 3 分;弃权方**不涨经验**
❌ **"加时怎么算"**:平局要决出胜负才进,常规联赛不打加时
❌ **"点球怎么算"**:加时还平才罚,**罚点球的进球不进球员统计(只算比赛结果)**
❌ **"球员没受伤怎么换人"**:可能是我方战术预设触发的换人(见 [第 5 章](05-lineup-basics.md)),不是受伤
