# 附录 2:名称

GoalXI 里有 **3 类名字**:球员 / 球队 / 球场。**生成规则各不相同**。这一章讲每种名字怎么来,能不能改。

---

## 一、3 类名字总览

| 名字类型 | 怎么来 | 玩家能改吗 | 说明 |
|---|---|---|---|
| **球员** | 名字池 + 国籍随机抽 | **不能** | 14 国籍池,生成后不变 |
| **球队** | **注册时**自己填(或默认 `New Club`) | **能**(`PATCH /teams/me`) | 改完有 audit 记录 |
| **球场** | 系统生成(中性的"Stadium") | **能**(`POST /teams/:id/stadium/rename`) | 改完有 audit 记录 |

> 3 类名字**互不影响**。你**不能**给球员改名,只能改球队 / 球场名。

---

## 二、球员名(自动生成,玩家不能改)

### 名字池(14 个国籍)

`libs/database/src/constants/name-database.ts` 提供了 **14 个国籍**的 first + last name 池:

| Code | 国籍 | 风格 |
|---|---|---|
| `GB` | England / Great Britain | English |
| `ES` | Spain | Spanish |
| `BR` | Brazil | Portuguese |
| `IT` | Italy | Italian |
| `FR` | France | French |
| `DE` | Germany | German |
| `NL` | Netherlands | Dutch |
| `AR` | Argentina | Spanish |
| `PT` | Portugal | Portuguese |
| `US` | United States | English |
| **`CN`** | **China(默认)** | **Chinese** |
| `JP` | Japan | Japanese |
| `KR` | South Korea | Korean |
| `MX` | Mexico | Spanish |

> 默认球队国籍 = `CN`,所以**大多数 NPC 球员是中国名**。

### 名字格式

**`{firstName} {lastName}`** — 两段,空格分开。每个国籍都有独立的 firstNames / lastNames 数组(每池约 20-30 个 first + 30+ 个 last)。

### 球员国籍 = 球队国籍 (70% 概率)

每生成一个球员时:
- **70% 概率** → 球员国籍 = 球队国籍(球队 CN → 球员 CN 中文名)
- **30% 概率** → 球员国籍 = 随机 14 国籍之一(球队 CN → 球员可能是 BR / IT / GB 等)

> **实战感知**:
> - 一支 CN 球队**绝大多数**球员都是中文名
> - **少量**"外援"(非 CN 国籍)出现在每支球队
> - 球队 CN 默认**让中文名占主导**,但不会 100%(有点多样性)

### 国籍不存在时 → fallback `GB`

如果一个球员的国籍字段不在 14 个池里(比如 `XX` 之类的脏数据):
- **fallback** = `GB` 池(英文)
- **不会报错** — 静默 fallback
- 玩家**不会看到**任何差异(只会看到"球员是个英文名")

### 生成时机

球员名在 **球队 onboarding / 注册**时一次性生成,之后**不变**:
- 初始 squad(每个队 16 球员)
- 球探的候选
- 替补 / 青年(系统生成的)

> **重要**:**球员名一旦定下来,不会因为转会 / 升级 / 跨联赛而变**。张三永远是张三,不会变成 John。

### 球员名不能改

**当前 MVP 阶段没有"改球员名"的 API**。球员名是身份标识的一部分(也写在 `player_event` 记录里),改名字会破坏历史事件的可读性。

> **未来可能**:Hattrick 有"改球员名"功能(收费 5 GC),GoalXI MVP 之后可能加。

---

## 三、球队名(注册时自填,可改)

### 注册时怎么填

球队注册(`POST /teams/claim` 或 `POST /teams`)时:
- `name` 字段(2-50 字符)
- 留空 → 默认 `New Club`

```
新俱乐部
```

### 改球队名

`PATCH /teams/me` with `{ name: "新名字" }`:
- 立即生效
- 触发 audit 记录(`name_change` 类型)
- 积分榜 / 杯赛 bracket / 转会列表 都立刻看到新名
- **不限制** 改名次数(但每次都记 audit)

### 什么**不能**改

球队其他字段**锁死**:
- `nationality` — 注册时定,跟 `name` 一样锁死
- `city` — 注册时定
- `foundedYear` — 创建年份自动戳
- `leagueId` — 升降级管,玩家不能改

> 球队名 / 国籍 / 城市都是身份的一部分,改了**会**破坏历史记录的可读性。

---

## 四、球场名(系统默认,可改)

### 默认名

球场创建时系统自动命名为**中性**"Stadium"(`libs/database/src/constants/stadium.constants.ts`):

```
Stadium
```

> 所有 NPC / BOT 球场都叫 "Stadium" — **没** "Camp Nou" / "Wembley" 之类的真实名字。

### 改球场名

`POST /teams/:teamId/stadium/rename` with `{ name: "新名" }`:
- 立即生效
- 触发 audit 记录(`stadium_rename` 类型)
- 出现在球队详情 / 比赛页(主队场地)

> 球场名是**纯展示**,不影响任何机制(不卖 / 不影响票务)。

### 球场名能改几次?

**MVP 阶段**:不限制(但每次都记 audit)。

---

## 五、名字的"国际性"(跨联赛 / 转会时)

### 球员跨联赛转会

当前 MVP **不支持跨联赛转会**(链 [第 18 章](18-transfer.md))。**如果未来支持**:
- 球员名**不变**(他是哪个国籍就是哪个国籍)
- 球队名 + 球场名 也都不变(转的是球员,不是球队)

### 球员同一联赛内转会

- 球员名**不变**
- 球队名**变**(从 A 队到 B 队)
- 球场名**变**(跟着球员走)

### 球探的球员名

球探候选(`GET /scouts/candidates`)也是用**同样**的 `getRandomNameByNationality()` 函数生成 — 跟主队球员**同源**。

---

## 六、怎么看我球员的国籍?

- 球员详情页 → 球员卡片 → **Nationality** 字段
- 雷达图旁边或下方
- 格式:2 字母 ISO 代码(`CN` / `BR` / `GB` 等)

> 球探系统也用 14 国籍池,跟你球队的池**完全一致**。

---

## 七、命名规则(`PATCH /teams/me` 等的校验)

| 字段 | 长度限制 | 字符 |
|---|---|---|
| `name`(球队) | 2-50 字符 | 任意 |
| `stadium name` | 1-50 字符 | 任意 |
| 球员 firstName / lastName | 不限(玩家不能改) | 出生时定 |

> **字符**目前不限制(`@StringFieldOptional({ minLength, maxLength })`),理论上你可以写 emoji / 中文 / 阿拉伯文。**空格**允许(可写"北京 FC")。

---

## 八、Bot / NPC 名字

### 球队名(1360 个 NPC 队)

- 全部是**中文名**(因为 `DEFAULT_TEAM_NATIONALITY = 'CN'`)
- 例:`北京 FC` / `上海联` / `广州竞技` 等
- 由 `team-onboarding-generator` 在 pyramid bootstrap 时生成
- **玩家**也可以参考这种命名风格给自己的球队起名

### 球场名(1360 个 NPC 球场)

- 全部 `Stadium`(中性默认)
- **玩家**可以给自己的球场起名字(中文 / 英文 / 任意)
- 未来 NPC 球场可能也支持随机命名(像 Hattrick 那样给每个队分配独特球场名)

### 球员名(1360 × 16 = 21,760 个 NPC 球员 + 球探候选)

- 多数 CN(70% 概率),少数 13 国籍之一
- 2 段名字,first + last
- 跟玩家球队**同样**的池

---

## 九、能做 / 不能做(关于名字)

### ✅ 能做

- 注册球队时**自己起名**(`POST /teams/claim`)
- **改球队名**(`PATCH /teams/me`)
- **改球场名**(`POST /teams/:teamId/stadium/rename`)
- 看球员的国籍(详情页)
- 在名字里用 emoji / 多语言

### ❌ 不能做(MVP 阶段)

- **改球员名** — 没 API,可能未来加
- **改球探的球员名** — 同上
- **改球队国籍** — 注册锁死
- **改球队城市** — 注册锁死
- **改球队成立年份** — 自动戳
- **改球队联赛归属** — 升降级管,玩家不能
- **改 NPC 球队 / 球场 / 球员名** — 全部系统生成

### ❌ MVP 限制

- **没有"起名校验"**(毒词过滤 / 重复名检查)— 理论上你可以改自己球队名跟别人重名
- **没有"改球员名"** 的付费 / 收费机制(像 Hattrick 5 GC 改 1 次)
- **没有"自动避讳"** 之类的特殊规则
- **没有"随机生成中文名"** 用拼音(直接用真实的中文人名池)

---

## 十、常见错误(关于名字)

❌ **"球员名是随机"**:**不是完全随机**,**70% 跟随球队国籍**,只有 30% 才是真随机
❌ **"中文球队 = 100% 中文球员"**:**不是**,70% CN + 30% 其他 13 国籍
❌ **"我能改球员名"**:**不能**(MVP 阶段)
❌ **"我能改球队国籍"**:**不能**(注册锁死)
❌ **"我能给球场起 '诺坎普' 这样的名"**:**能**(`POST /teams/:id/stadium/rename`)
❌ **"球队名跟别人重名会失败"**:**不会** — 重复名允许
❌ **"改球队名会清空积分"**:**不会** — 名字是展示层,不影响数据
❌ **"NPC 球员有独特名字"**:**多数有**(`getRandomNameByNationality()`),但球场都是 `Stadium`
❌ **"球员转会后会改名字"**:**不会** — 球员名永久绑定
❌ **"Bot 球队 = 真实豪门名字"**:**不会** — 都是 CN 名字(`北京 FC` 之类),不模拟真实俱乐部

---

## 十一、实战流程(起名技巧)

### 注册球队时

- **2-50 字符** — 别太长也别太短
- **可用任意语言** — 中文 / 英文 / emoji 都行
- **建议**:中文名 + "FC" / "联" / "竞技" / "体育" 后缀
  - 例:`北京蓝鹰 FC` / `上海 1992 联` / `广州群星`
- **避免**:
  - 跟现有 NPC 球队名撞(虽允许但不优雅)
  - 完全空着(系统会用 `New Club`,很难看)
  - 太长(50 字符上限,排版丑)

### 改球场名

- 跟球队名风格一致(球队叫"北京蓝鹰",球场可以叫"蓝鹰体育场")
- 唯一性不强制
- 改完会有 audit 记录(暂时不显示给玩家看)

### 看球员国籍

- 球员详情页 → Nationality 字段
- 用来**判断球员背景**:
  - CN 球员 = 国内青训
  - 13 国籍之一 = "外援"
  - 外援不增加工资或特殊加成(目前 MVP 阶段)

---

## 十二、跟其他概念的关系

| 概念 | 关系 |
|---|---|
| **球队注册**(第 1 章) | 球队名 + 国籍在 claim 时定 |
| **球员属性**(第 4 章) | 球员名是身份标识,不影响任何属性 |
| **转会**(第 18 章) | 球员转会**不改名**,只改 `teamId` |
| **特性 / 潜力 / PWI**(第 4 章) | 跟名字**完全无关** — 名字不影响能力 |
| **球探**(第 19 章) | 球探候选用**同样**的 14 国籍池 |
| **球场**(第 11 章) | 球场名**纯展示**,不影响建设进度 / 票务 |
