# 游戏介绍

欢迎来到 **GoalXI** —— 一个虚拟足球经营游戏,你扮演一支真实球员球队的主教练和老板,带它从底层联赛一路打上冠军。

## 这是什么游戏

GoalXI 让你:

- **接管一支小球队** —— 从最低级别的联赛起步,初始阵容、球场、资金都到位
- **跟全球玩家竞争** —— 同一小组的真实玩家 + 用 AI 填充的 BOT 队,真实对抗
- **一手打造球队** —— 战术、阵容、训练、转会、青训、财政,所有事都你说了算
- **一路向上** —— **多层联赛金字塔**(层数可扩展 / 收缩,具体看当前游戏配置),打进顶级联赛,争冠

比赛是**赛前布阵 + 比赛日看直播**的模式,不是回合制 / 也不是让你边看边指挥:

- **赛前**(开球前 10 分钟之前) → 你设置**首发 + 替补 + 战术 + 球队指示**
- **开球前 10 分钟** → 战术锁定,改不了
- **比赛日** → 比赛按你的设定**自动模拟**,事件一条条弹出来(比分实时更新,像在盯直播)
- **比赛进行中** → 玩家**没有临场操作**(不换人 / 不调战术 / 不下指示)
- **赛后** → 看完整时间轴 + 球员评分 + 事件历史

所以胜负在**赛前布阵**就基本决定了,看直播是看结果。战术的活全在比赛日之前。

## 你扮演什么

你一人两角:

- **主教练** —— 排首发,定战术,管训练,安排比赛日指示(**比赛开始后不能调整**)
- **俱乐部老板** —— 决定买谁卖谁,球场升级,签 / 解雇教练和职员

具体日常:

- **战术 / 阵容** —— 阵型,首发 + 替补,比赛日的指示
- **训练** —— 安排球队这周练什么(体能 / 技术 / 心理 / 定位球 / GK)
- **转会** —— 在公开市场买人、挂牌卖人、跟踪目标
- **青训** —— 球探网络招年轻人,培养成主力
- **财政** —— 工资、上座率、球场升级、引援预算
- **职员** —— 雇佣 7 类教练 / 医生 / 心理师

你不用每天都上线。但要想赢就得 **持续经营** —— 球员需要长期培养,球队需要长期规划。

## 核心循环:GoalXI 周

一周 7 天的典型节奏(联赛 vs 杯赛可能略有差异):

| 日 | 主要事件 |
|---|---|
| **周一** | 老将技能微衰退(后台跑,你不用管) |
| **周二** | 杯赛日 |
| **周三** | 联赛日 #1 |
| **周四** | 训练结算 + 工资发放 + 衰退结算 + 解雇窗口(青训 reveal 也在周四) |
| **周五** | 部分杯赛日 |
| **周六** | 联赛日 #2 |
| **周日** | 自由安排:挂牌 / 签约 / 升级球场 / 调整训练 |

比赛统一 **UTC 6:00 开球**(北京时间 14:00)。开球前 **10 分钟** 锁定战术,过时不改。

每赛季 **16 周**,结束后升降级 + 杯赛淘汰 + 颁奖 + 赛季存档。

## 怎么赢

没有单一"通关"路径。几条路都算赢:

- **联赛冠军** —— 从 L4 一路打上 L1,顶级联赛冠军是终极目标
- **杯赛 / 季后赛** —— 杯赛出线,赢杯赛冠军;季后赛也是高荣誉
- **青训** —— 把年轻人从 L0 培养到 L20"化境",成就感最高
- **转会** —— 低买高卖,做出转会利润,养一支商业化的球队
- **国家队** —— 让自己球员进国家队,代表国家踢国际赛(经验 5x 加速)

**长期主义是核心**。急不来。玩得越久越有味道 —— 你的青训树、转会策略、阵容默契,3-4 个赛季后才真正见效。

## 跟其他玩家怎么互动

GoalXI 不是单机 —— 你的对手是**真实玩家**:

- **联赛对战** —— 同一小组 7-8 队,主客场两回合,胜 3 平 1 负 0
- **杯赛** —— 同档次抽签,可能反复遇到熟悉的对手
- **转会市场** —— 所有球队共用一个公开市场,挂牌的球员所有人都能出价
- **论坛** —— 玩家社区,4 个分类(公告 / 综合 / 战术 / 转会),可以发帖讨论

所以你的对手是**会思考的人**,不是脚本。胜在战术、执行、和长期眼光。

## 我们的最佳建议

1. **先读完这本手册** —— 头几章是核心,后面按需翻(随时搜)
2. **别急着买人** —— 初始阵容 + 工资空间够用一段时间,先搞懂战术再说
3. **多看比赛直播** —— 看比赛日的事件流,知道你的布阵实际效果。雷达图 + PWI 看不出来的现场表现,直播能看到
4. **多去论坛** —— 战术 / 转会 / 青训 几个分类都有老玩家分享经验
5. **保持长期主义** —— 一赛季赢不了冠军没关系,3-4 个赛季后你的青训 + 转会策略会显现

> 这本手册不写"**GoalXI 怎么实现**",只写"**怎么玩**"。技术细节不在玩家视角里。
